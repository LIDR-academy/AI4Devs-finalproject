# BPMN Modeler with OOP Extensions - PRD

## Original Problem Statement
Aplicacion web completa de Modelador BPMN con extensiones OOP. Herramienta profesional para diseñar, versionar y colaborar en diagramas BPMN 2.0 con metadatos orientados a objetos.

## Architecture
- **Frontend**: React 19 + Tailwind CSS + shadcn/ui + bpmn-js v17
- **Backend**: FastAPI (Python) + MongoDB + httpx (GitHub API)
- **AI**: Gemini 2.5 Flash + GPT 4.1 (Emergent LLM Key) + MiniMax M2.7 (Anthropic API)
- **Auth**: Emergent-based Google social login + Demo login
- **i18n**: React Context + MongoDB overrides (6 languages)
- **Roles**: free (restricted), subscription (default), admin
