# 🌟 Ejemplos de Patrones Agnósticos (Few-Shot Exemplars)

Este directorio contiene plantillas y patrones de diseño en **pseudocódigo 100% agnóstico**. El agente de IA debe consultar estas plantillas estructurales para extrapolar los patrones de arquitectura limpia a cualquier lenguaje de programación (TypeScript, Python, Java, Go, C#, Rust, etc.).

## 📂 Índice de Patrones Agnósticos:

2. **[Controlador HTTP REST](file:///home/lacruzjd/entrgafinal/AI4Devs-finalproject/.agents/examples/02_controller_pattern.example.md):** Estructura abstracta de sanitización de entradas HTTP, invocación del caso de uso y manejo centralizado de excepciones.
3. **[Componente UI y Estados Defensivos](file:///home/lacruzjd/entrgafinal/AI4Devs-finalproject/.agents/examples/03_ui_component_pattern.example.md):** Estructura abstracta de desacoplamiento por repositorio, separación de hooks/estado y renderizado de los 4 estados defensivos con ergonomía táctil.
