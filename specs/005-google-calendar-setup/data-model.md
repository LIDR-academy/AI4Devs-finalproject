# Data Model: Google Calendar Infrastructure

**Phase**: 1 — Design & Contracts
**Date**: 2026-07-15

## Overview

This feature provisions GCP cloud resources — not application database entities. The "data model" here describes the GCP resources and their relationships, since the scheduling engine will reference these resources at runtime via environment variables.

## Resource Model

### Google Cloud Project

| Attribute | Value |
|-----------|-------|
| **ID** | `coacher-scheduling-engine` |
| **Purpose** | Container for Calendar API, Service Account, and billing |
| **Billing** | Linked active billing account (required for Calendar API) |
| **Created by** | Developer via `gcloud projects create` or GCP Console |
| **Consumed by** | All `gcloud` commands reference this project |

**Relationships**:
- Contains **Calendar API** (enabled service)
- Contains **Service Account** (IAM resource)

### Calendar API

| Attribute | Value |
|-----------|-------|
| **Service name** | `calendar-json.googleapis.com` |
| **State** | Enabled on the GCP project |
| **Quota** | 1,000,000 requests/day (free tier) |
| **Enabled by** | Developer via `gcloud services enable` |

**Relationships**:
- Enabled on **GCP Project**
- Consumed by **Service Account** (authenticated calls)

### Service Account

| Attribute | Value |
|-----------|-------|
| **Email** | `scheduling-engine-calendar-sa@coacher-scheduling-engine.iam.gserviceaccount.com` |
| **Display name** | "Scheduling Engine Calendar Service Account" |
| **IAM roles** | None (calendar access via Calendar sharing, not IAM) |
| **Key file** | JSON key stored outside version control (path configured via env var) |
| **Created by** | Developer via `gcloud iam service-accounts create` |

**Relationships**:
- Belongs to **GCP Project**
- Has 1 JSON **Key** file
- Granted writer access to **System Calendars** (×3: dev, staging, prod)

### Service Account Key

| Attribute | Value |
|-----------|-------|
| **Type** | JSON private key |
| **File path** | Configured via `GOOGLE_CALENDAR_SA_KEY_PATH` env var |
| **Storage** | Outside git repository (`.env` file or secrets manager) |
| **Rotation** | Delete old key + generate new one via `gcloud iam service-accounts keys` commands |
| **Generated by** | Developer via `gcloud iam service-accounts keys create` |

**Relationships**:
- Belongs to **Service Account**
- Referenced by scheduling engine at runtime

### System Calendar (per environment)

| Attribute | Dev | Staging | Production |
|-----------|-----|---------|------------|
| **Name** | Coacher Scheduling Engine [dev] | Coacher Scheduling Engine [staging] | Coacher Scheduling Engine [prod] |
| **Calendar ID** | `GOOGLE_CALENDAR_ID_DEV` env var | `GOOGLE_CALENDAR_ID_STAGING` env var | `GOOGLE_CALENDAR_ID_PROD` env var |
| **Timezone** | Gym's local timezone | Gym's local timezone | Gym's local timezone |
| **Shared with SA** | Writer | Writer | Writer |
| **Created by** | Developer via Google Calendar UI | Developer via Google Calendar UI | Developer via Google Calendar UI |

**Relationships**:
- Each is shared (writer) with the **Service Account**
- Each is referenced by the scheduling engine via its **Calendar ID** env var

## Configuration Dependencies

The following environment variables must be set for the scheduling engine to function:

```
GOOGLE_CALENDAR_SA_EMAIL=scheduling-engine-calendar-sa@coacher-scheduling-engine.iam.gserviceaccount.com
GOOGLE_CALENDAR_SA_KEY_PATH=/path/to/coacher-calendar-sa-key.json
GOOGLE_CALENDAR_ID_DEV=<dev-calendar-id>
GOOGLE_CALENDAR_ID_STAGING=<staging-calendar-id>
GOOGLE_CALENDAR_ID_PROD=<production-calendar-id>
```

## Lifecycle & State Transitions

| Event | Effect |
|-------|--------|
| SA key rotated | Update `GOOGLE_CALENDAR_SA_KEY_PATH` and file contents (or replace file at same path). Old key immediately invalid. |
| Calendar deleted accidentally | Create new calendar in Google Calendar UI → share with SA → update the corresponding `GOOGLE_CALENDAR_ID_*` env var. |
| SA deleted | All calendars lose access. Create new SA → generate key → re-share all calendars → update env vars. |
| Billing disabled | All Calendar API calls fail. Re-enable billing in GCP Console. |
