Coordinar la implementación funcional del MVP de Entrega 2.

&#x20;  - Confirmar historias mínimas.



2\. Delivery Manager Agent

&#x20;  - Ordenar tareas.

3\. Architect Agent

4\. Backend Agent

&#x20;  - Implementar API, Prisma, seed y endpoints.



5\. Edge Agent

6\. Frontend Agent

7\. QA Agent

&#x20;  - Probar flujo principal.



8\. Governance Agent

9\. Documenter Agent

\## Definition of Done

\- Backend ejecutable.

\- Frontend ejecutable.

\- Edge en modo simulación.

\- Flujo principal demostrable.

\- README actualizado.

\- Evidencias disponibles.

\- Prompts registrados.
