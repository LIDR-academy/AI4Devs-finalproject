\# Command Generate Codex Prompt



\## Objetivo

Generar un prompt listo para ejecutar en Codex, usando agentes, commands, skills, playbooks y archivos de contexto del proyecto.



\## Inputs requeridos

\- Objetivo de la tarea.

\- Agente principal.

\- Command a usar.

\- Skills necesarias.

\- Playbook si aplica.

\- Archivos de contexto.

\- Archivo destino.

\- Restricciones.



\## Pasos

1\. Revisar AGENTS.md.

2\. Identificar el agente adecuado.

3\. Identificar command, skills y playbook necesarios.

4\. Construir un prompt claro y ejecutable.

5\. Incluir archivos que Codex debe leer.

6\. Incluir archivo destino.

7\. Incluir restricciones.

8\. Incluir resumen esperado al finalizar.



\## Output esperado

Un prompt en formato texto, listo para copiar y pegar en Codex.



\## Reglas

\- El prompt debe ser específico.

\- Debe indicar claramente qué archivos puede modificar.

\- Debe indicar qué archivos no puede modificar.

\- Debe pedir resumen final.

\- Debe evitar tareas demasiado grandes.
