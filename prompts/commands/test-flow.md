# Command Test Flow

## Objetivo

Probar flujo principal de Entrega 2.

## Flujo

1. Levantar backend.
2. Ejecutar seed.
3. Identificar camion por QR o `truckCode`.
4. Crear sesion.
5. Registrar cubos.
6. Registrar accion robot.
7. Consultar dashboard.
8. Levantar frontend.
9. Validar visualizacion.

## Output

- Checklist.
- Evidencia.
- Defectos.
- Pendientes.
