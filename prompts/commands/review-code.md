\# Command Review Code



\## Objetivo

Revisar cambios antes de commit o PR.



\## Pasos

1\. Revisar alcance.

2\. Revisar errores evidentes.

3\. Revisar seguridad básica.

4\. Revisar mantenibilidad.

5\. Revisar documentación.

6\. Separar findings críticos de mejoras.



\## Output

\- Findings críticos.

\- Mejoras sugeridas.

\- Veredicto: listo / requiere ajuste.
