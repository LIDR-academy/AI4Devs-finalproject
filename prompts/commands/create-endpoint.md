\# Command Create Endpoint



\## Objetivo

Crear un endpoint REST del MVP.



\## Pasos

1\. Revisar contrato esperado.

2\. Revisar modelo de datos.

3\. Crear ruta.

4\. Crear controlador.

5\. Crear servicio.

6\. Validar request.

7\. Manejar errores.

8\. Documentar ejemplo.



\## Output

\- Endpoint funcionando.

\- Ejemplo request/response.

\- Comando de prueba.
