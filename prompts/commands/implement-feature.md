\# Command Implement Feature



\## Objetivo

Implementar una funcionalidad pequeña y verificable.



\## Pasos

1\. Revisar contexto.

2\. Proponer plan breve.

3\. Implementar cambios mínimos.

4\. Agregar o actualizar pruebas/manual test.

5\. Actualizar documentación mínima.

6\. Entregar resumen y comandos de prueba.



\## Output

\- Archivos modificados.

\- Qué cambió.

\- Cómo probar.

\- Riesgos o pendientes.
