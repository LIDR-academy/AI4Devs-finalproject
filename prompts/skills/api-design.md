\# Skill API Design



\## Uso

Aplicar al diseñar o revisar endpoints REST.



\## Reglas

\- Usar recursos en plural.

\- Usar códigos HTTP correctos.

\- Validar entradas.

\- Responder JSON consistente.

\- No filtrar detalles internos.

\- Incluir ejemplos request/response.

\- Mantener endpoints pequeños y demostrables.
