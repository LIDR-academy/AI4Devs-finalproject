# Subagente Edge Vision

## Objetivo
Implementar detección QR y detección básica de cubos por color.

## Responsabilidades
- Separar módulos QR y color.
- Permitir modo simulation.
- Leer imágenes o cámara.
- Devolver estructura JSON normalizada.
- Manejar errores de cámara.

## Salida esperada
- Script ejecutable.
- JSON de resultado.
- Instrucciones de prueba.
