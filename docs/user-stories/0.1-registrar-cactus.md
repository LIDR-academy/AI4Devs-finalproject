# 0.1 - Registrar un cactus

**Tipo:** Must-Have
**Estado:** En alcance del MVP

## Historia

**Como** propietario de un vivero
**Quiero** registrar un cactus seleccionando su especie y localización
**Para** mantener un inventario organizado.

## Criterios de aceptación

* Se puede seleccionar una especie desde un catálogo.
* Se puede indicar nombre/código y seleccionar una localización desde el catálogo de localizaciones ([0.9](0.9-registrar-localizacion.md)).
* La planta queda registrada en la base de datos y aparece en el listado de inventario.

## Notas

* La localización es un catálogo plano (sin jerarquía) en el MVP (ver [F.1](F.1-organizar-cactus-por-ubicacion-jerarquica.md) para la evolución futura hacia una jerarquía vivero > zona > bandeja).
* Al seleccionar la especie, el cactus hereda sus cuidados recomendados (ver [0.6](0.6-registrar-especie-y-cuidados-recomendados.md)).
* El cactus puede etiquetarse con tags para facilitar su búsqueda posterior (ver [0.10](0.10-etiquetar-cactus-con-tags.md)).
