# F.7 - Identificación de especie por fotografía

**Estado:** Fuera de alcance del MVP / Roadmap

## Historia

**Como** propietario de un vivero
**Quiero** subir una foto de un cactus y que la IA proponga automáticamente género, especie y estado aparente
**Para** agilizar el alta de nuevos ejemplares (registro asistido).

## Ejemplo

```text
Género: Ariocarpus
Especie: retusus
Estado: Bueno
Necesita trasplante: No
```

El usuario solo confirmaría o corregiría la propuesta.

## Notas

* Distinta de [F.6](F.6-deteccion-de-estres-por-fotografia.md): aquí el objetivo es identificar la especie, no detectar un problema de salud.
