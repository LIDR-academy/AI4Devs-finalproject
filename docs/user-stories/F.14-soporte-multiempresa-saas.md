# F.14 - Soporte multiempresa / modelo SaaS

**Estado:** Fuera de alcance del MVP / Roadmap

## Historia

**Como** operador de la plataforma
**Quiero** que varios viveros u organizaciones distintas puedan usar la plataforma de forma aislada (multiempresa)
**Para** poder ofrecer Cactify como un SaaS a terceros, no solo para una colección personal.

## Notas

* El MVP se diseña pensando en una colección/usuario personal, pero el modelo de datos debe dejar la puerta abierta a añadir organizaciones más adelante sin rediseñar desde cero.
