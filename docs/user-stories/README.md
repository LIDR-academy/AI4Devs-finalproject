# Historias de usuario

Índice completo de historias de usuario del proyecto **Cactify**.

## Convención de numeración

* **`0.x`** — Historias que entran en el alcance del MVP (Must-Have o Should-Have documentadas para la primera entrega).
* **`F.x`** — Historias fuera de alcance / roadmap futuro. Se documentan para dejar constancia de la visión de producto, pero no se implementan en el MVP.

Dentro de cada bloque, el orden de los archivos es el orden de prioridad.
