# F.4 - Carga automática de lecturas desde sensor IoT

**Estado:** Fuera de alcance del MVP / Roadmap

## Historia

**Como** propietario de un vivero
**Quiero** recibir automáticamente lecturas de humedad, temperatura y luz desde un dispositivo (p. ej. ESP32)
**Para** no tener que introducir los datos manualmente.

## Notas

* Decisión explícita: el IoT se documenta como visión de producto a futuro, pero queda **fuera del proyecto** del MVP. El registro de lecturas en el MVP es siempre manual (ver [0.2](0.2-registrar-condiciones-de-cultivo.md)).
* Recomendación recibida en la asignatura: evitar construir hardware/sensores para esta entrega, ya que dispara el alcance de ~30 horas a un proyecto de varios meses.
