# F.2 - Registrar cuidados por lote

**Estado:** Fuera de alcance del MVP / Roadmap

## Historia

**Como** propietario de una colección grande
**Quiero** registrar un cuidado (p. ej. riego) sobre todos los cactus de una ubicación a la vez
**Para** no tener que actualizar cada ejemplar manualmente.

## Ejemplo

```text
Ubicación: Bandeja A3
Cuidado: Riego
Fecha: 27/07/2026
Plantas afectadas: 24
```

## Notas

* Depende de tener una ubicación con varias plantas asociadas de forma clara (ver [F.1](F.1-organizar-cactus-por-ubicacion-jerarquica.md)).
* Identificada en la conversación inicial como la funcionalidad más representativa del problema real de gestionar cientos de plantas, pero se dejó fuera del MVP final para mantener el alcance mínimo de la primera entrega.
