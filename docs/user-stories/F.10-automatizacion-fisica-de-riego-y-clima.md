# F.10 - Automatización física de riego y clima ("Autopilot")

**Estado:** Fuera de alcance del MVP / Roadmap (visión a largo plazo)

## Historia

**Como** propietario de un vivero
**Quiero** que el sistema decida y ejecute físicamente cuándo regar, ventilar o sombrear
**Para** que la colección pueda mantenerse sin supervisión constante (p. ej. durante unas vacaciones).

## Notas

* Esta es la visión de producto a largo plazo ("Autopilot para viveros"), pero implica hardware (bombas, motores) y no debe ser necesaria para completar el flujo principal del MVP.
* El MVP se limita a **recomendar**, nunca a actuar de forma autónoma.
