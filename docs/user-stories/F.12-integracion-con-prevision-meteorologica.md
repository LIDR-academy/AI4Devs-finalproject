# F.12 - Integración con previsión meteorológica

**Estado:** Fuera de alcance del MVP / Roadmap

## Historia

**Como** propietario de un vivero con plantas en exterior
**Quiero** que el sistema tenga en cuenta la previsión meteorológica al generar recomendaciones
**Para** evitar regar justo antes de una lluvia o anticipar una ola de calor.

## Notas

* Relevante sobre todo para colecciones en exterior o invernadero, no tanto en interior.
* Requiere integración con una API meteorológica externa.
