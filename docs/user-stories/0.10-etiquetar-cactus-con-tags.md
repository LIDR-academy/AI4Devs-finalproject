# 0.10 - Etiquetar cactus con tags

**Tipo:** Must-Have (soporte)
**Estado:** En alcance del MVP

## Historia

**Como** propietario de un vivero
**Quiero** asignar tags a mis cactus (p. ej. "globular", "pequeño", "sin espinas", "híbrido")
**Para** poder clasificarlos y encontrarlos fácilmente más adelante.

## Criterios de aceptación

* Se puede crear un tag nuevo indicando un nombre, o reutilizar uno ya existente del catálogo.
* Se pueden asignar varios tags a un mismo cactus, y un mismo tag a varios cactus.
* Al editar un cactus se puede añadir o quitar tags.
* Los nombres de tag son únicos en el catálogo (no se duplican por mayúsculas/minúsculas o espacios).

## Notas

* Relación N:M entre `Plant` y `Tag` mediante la tabla intermedia `PlantTag` (ver [modelo de datos](../diagramas/modelo-datos.md)).
* Esta historia es la base de la búsqueda por tags ([0.11](0.11-buscar-cactus-por-tag-o-localizacion.md)).
