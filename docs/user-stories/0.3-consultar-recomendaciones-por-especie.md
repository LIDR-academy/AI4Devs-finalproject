# 0.3 - Consultar recomendaciones por especie

**Tipo:** Must-Have
**Estado:** En alcance del MVP

## Historia

**Como** propietario de un vivero
**Quiero** ver los rangos recomendados para la especie seleccionada
**Para** saber cuáles son las condiciones ideales de cultivo.

## Criterios de aceptación

* La ficha muestra humedad, temperatura, luz y frecuencia de riego recomendadas.
* Los datos provienen del catálogo de especies (entidad `Species`), no de la IA.

## Notas

* Estos rangos son la base de conocimiento determinista que luego usa la IA para generar recomendaciones (ver [0.4](0.4-obtener-analisis-de-ia.md)).
