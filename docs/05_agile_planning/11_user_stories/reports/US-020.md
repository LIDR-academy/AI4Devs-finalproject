# 📖 Historia de Usuario: US-020 — Indicador TRR Real en el Dashboard de Reportes

## 👤 Rol del Usuario
Como Administrador,

## 🎯 Objetivo / Valor de Negocio
Quiero visualizar el tiempo real promedio de rotación de remanentes (TRR efectivo) en el dashboard de reportes, para verificar si el objetivo de 72 horas definido en el producto se cumple en la práctica.

## 📌 Justificación (Gap Analysis)
El KPI #2 del PRD (`docs/01_product_definition/02_prd.md §1.3`) define la Tasa de Rotación de Remanentes (TRR < 72h) como métrica de éxito explícita del producto. El sistema fuerza la regla de negocio (bloqueo de remanentes vencidos a las 72h) pero nunca calcula ni reporta el tiempo **real** promedio de rotación — nadie puede saber hoy si el objetivo se cumple en la práctica o solo en el diseño.

## 🗣️ Decisiones de Negocio Consultadas con el Humano (Guard 28)
*   **Pregunta:** Un remanente descartado (merma) nunca llega a "totalmente consumido". ¿Cómo se trata en el cálculo del TRR promedio?
*   **Respuesta:** Se incluye el tiempo hasta el descarte — el TRR mide el ciclo de vida completo del remanente (éxito o fracaso), no solo el consumo exitoso.

---

## 🥒 Criterios de Aceptación (BDD - Sintaxis Gherkin)

### Escenario 1: Cálculo del Promedio con Muestra Válida
- **Given** 3 remanentes que alcanzaron estado terminal (`EXHAUSTED` o `DISCARDED` — el enum real de `Remanente.status`) dentro del rango consultado, con tiempos transcurridos de 24h, 48h y 96h respectivamente.
- **When** El Administrador consulta el indicador TRR del dashboard (`GET /api/v1/reports/rotation-metrics`).
- **Then** El sistema retorna `averageTrrHours: 56.0`, `targetTrrHours: 72` y `sampleSize: 3`.

### Escenario 2: Rango sin Remanentes Terminados — Estado Vacío Explícito
- **Given** Ningún remanente alcanzó estado terminal en el rango de fechas consultado.
- **When** El Administrador consulta el indicador TRR.
- **Then** El sistema retorna `sampleSize: 0` y la UI muestra un estado vacío explícito — nunca `"0h"`, que se leería engañosamente como un resultado perfecto.
