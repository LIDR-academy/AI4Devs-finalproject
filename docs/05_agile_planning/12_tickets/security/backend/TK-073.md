# 🎟️ Ticket Técnico: TK-073 — Backend Dynamic RBAC

## 🎯 Objetivo
Implementar la infraestructura relacional de base de datos (`Role`, `Permission`, `RolePermission`), repositorios, casos de uso (`GetRolesUseCase`, `CreateRoleUseCase`, `UpdateRolePermissionsUseCase`), controlador HTTP `roles.controller.ts` y middleware Express de autorización `authorizePermissions(...permissions)`.

---

## 🛠️ Tareas Técnicas
1. Definir entidades de dominio `Role`, `Permission` y Value Objects asociados.
2. Crear repositorio Prisma `PrismaRoleRepository.ts` e in-memory `InMemoryRoleRepository.ts`.
3. Implementar controlador `roles.controller.ts` con esquemas de validación Zod.
4. Implementar middleware `authorizePermissions(...permissions)` validando los permisos contenidos en el JWT emitido en login.
5. Actualizar el script de seed (`prisma/seed.ts`) sembrando permisos estándar y roles base (`ADMIN`, `WAREHOUSE_STAFF`, `COOK`).

---

## 🧪 Plan de Pruebas (TDD)
- Pruebas unitarias para `CreateRoleUseCase` y `UpdateRolePermissionsUseCase`.
- Pruebas de integración HTTP para `GET /api/v1/roles`, `POST /api/v1/roles` y `PUT /api/v1/roles/:id`.
- Pruebas del middleware `authorizePermissions` (`200 OK` si el rol contiene el permiso, `403 Forbidden` RFC 7807 si carece de él).
