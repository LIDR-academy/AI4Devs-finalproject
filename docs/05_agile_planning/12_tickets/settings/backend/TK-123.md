# 🎟️ TK-123: Modelo de Persistencia y Endpoints de Configuración de IA (Backend)

## 📝 Descripción
Implementar el modelo de datos `AiConfiguration`, los puertos de persistencia y los endpoints REST para consultar (`GET /api/v1/settings/ai`), actualizar (`PUT /api/v1/settings/ai`) y diagnosticar (`POST /api/v1/settings/ai/test`) la conectividad del agente de IA configurado, garantizando que las credenciales se almacenen cifradas con AES-256-GCM y nunca se expongan en texto claro.

*   **ID US Relacionada:** [`US-034`](../../11_user_stories/settings/US-034_configuracion_agente_ia.md)
*   **Módulo / Vertical Slice:** `settings`
*   **Estimación (Story Points):** 3
*   **Prioridad MoSCoW:** Should Have
*   **Prerrequisitos:** Autenticación y control de roles (`ADMIN`) activos (`US-015`).

---

## 🗣️ Decisiones de Negocio Consultadas (Guard 28)
1.  **Cifrado en reposo:** AES-256-GCM nativo con `crypto`. En respuestas HTTP solo se expone `hasApiKey: true|false`.
2.  **Fallback de entorno:** Si la base de datos no tiene clave pero existe `AI_API_KEY` en `process.env`, se utiliza dicha variable.
3.  **Restricción de rol:** Exclusivo para `ADMIN` (responde `403 Forbidden` a otros roles).
4.  **Cota de temperatura:** Validación estricta Zod en el payload de actualización: `temperature <= 0.2` (Guard 9).

---

## 🔀 Alcance de Modificación (Hexagonal Layers)
*   **Domain:**
    *   Entidad `AiConfiguration.ts` en `domain/settings/entities/`.
    *   Value Objects: `AiProvider.ts` (`GEMINI`, `OPENAI_COMPATIBLE`, `HEURISTIC`).
    *   Puerto `IAiConfigurationRepository.ts`.
*   **Application:**
    *   `GetAiConfigUseCase.ts`: Retorna la configuración activa enmascarando la API key.
    *   `UpdateAiConfigUseCase.ts`: Cifra la nueva clave si se provee y actualiza parámetros.
    *   `TestAiConnectionUseCase.ts`: Ejecuta un ping contra el conector del proveedor configurado.
*   **Infrastructure:**
    *   Modelo `AiConfiguration` en `prisma/schema.prisma` y migración aditiva.
    *   `PrismaAiConfigurationRepository.ts` e `InMemoryAiConfigurationRepository.ts`.
    *   Servicio de cifrado `CredentialEncryptionService.ts` (`crypto` AES-256-GCM).
    *   Controlador `aiSettings.controller.ts` y rutas registradas en `apps/backend/src/infrastructure/http/routes/settings.routes.ts`.
    *   Validadores Zod: `updateAiConfigSchema`.

---

## ✅ Criterios de Aceptación & DoD (Definition of Done)
1. `GET /api/v1/settings/ai` requiere rol `ADMIN` y retorna 200 con `{ provider, modelName, hasApiKey, temperature, ... }`.
2. `PUT /api/v1/settings/ai` actualiza los parámetros y cifra la clave sin guardarla en texto plano.
3. `POST /api/v1/settings/ai/test` ejecuta un ping y retorna `{ success: true, latencyMs: number }`.
4. Tests unitarios y de integración pasando al 100% con fakes en memoria (`InMemoryAiConfigurationRepository`).
