# 🎟️ TK-077: Backend Admin PIN Recovery via Email Token & Magic Link

> **Navegación del Framework SDD:**  
> [📖 Índice de Tickets](../../indice_tickets.md) | [Siguiente: TK-077-FE](../frontend/TK-077-FE.md)

---

## 📝 Descripción
Implementa los endpoints de backend y casos de uso en arquitectura hexagonal para la recuperación de acceso del Administrador mediante token temporal criptográfico de 15 minutos enviado por correo electrónico:
1. `POST /api/v1/auth/forgot-pin`: Genera un token firmado HMAC-SHA256 con expiración a 15 min, lo asocia al hash en el modelo User y despacha el correo mediante `IEmailService`.
2. `POST /api/v1/auth/reset-pin`: Valida el token contra el hash persistido, actualiza el PIN con salting criptográfico `scrypt`, reactiva la cuenta a `ACTIVE` y resetea los intentos fallidos a `0`.

---

## 🔀 Alcance de Modificación (Hexagonal Layers)

### Domain:
- `User.ts`: Atributos opcionales `email?: string`, `resetTokenHash?: string`, `resetTokenExpires?: Date`.
- `IEmailService.ts`: Puerto abstracto para mensajería de recuperación.

### Application:
- `RequestAdminPinResetUseCase.ts`: Validación de correo, generación de token de 15 min, mitigación anti-enumeración de usuarios.
- `ResetAdminPinUseCase.ts`: Verificación de validez y caducidad, actualización de PIN y reactivación de cuenta.

### Infrastructure:
- `PrismaUserRepository.ts` & `InMemoryUserRepository.ts`: Método `findByEmail(email: string)`.
- `ConsoleEmailService.ts`: Adaptador por defecto de envío a logs en entorno local/test.
- `auth.controller.ts` & `auth.routes.ts`: Endpoints protegidos con esquemas Zod y rate-limiting.

---

## ✅ Criterios de Aceptación & DoD
1. **Seguridad Anti-Enumeración**: Respuesta idéntica HTTP 200 independientemente de si el correo existe o no en el sistema.
2. **Expiración Estricta**: Token rechazado con HTTP 401 si supera los 15 minutos.
3. **One-Time Token**: El token se borra tras ser utilizado satisfactoriamente.
4. **Verificación**: 100% pruebas pasando (`pnpm test`) y 0 errores de build (`pnpm run build`).
