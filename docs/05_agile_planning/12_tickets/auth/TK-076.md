# 🎟️ TK-076: Complete Super Admin CRUD Suite (Personal, Roles y Sectores)

> **Navegación del Framework SDD:**  
> [📖 Índice de Tickets](../../indice_tickets.md) | [Siguiente: Matriz de Trazabilidad](../../../13_matriz_trazabilidad.md)

---

## 📝 Descripción
Consolida la suite completa de administración CRUD para el Super Administrador (`ADMIN`):
1. **Gestión de Personal Registrado**: Listado continuo de trabajadores, edición de datos (nombre, rol dinámico asignado, PIN) y cambio de estado (`ACTIVE`/`BLOCKED`).
2. **Gestión de Roles Dinámicos**: Alta de roles personalizados, edición de matriz de permisos y eliminación de roles dinámicos no del sistema.
3. **Gestión de Sectores de Almacenamiento**: Alta, edición (nombre, tipo, descripción), conmutación de estado activo/inactivo y eliminación de sectores físicos.

---

## 🔀 Alcance de Modificación (Hexagonal Layers)

### Backend:
- `UpdateUserUseCase.ts`: Actualiza nombre, rol y/o PIN de un usuario.
- `auth.routes.ts`: `PUT /api/v1/auth/users/:id` protegido por `authMiddleware` + `requireRole('ADMIN')`.
- `roles.controller.ts` & `security.routes.ts`: `DELETE /api/v1/roles/:id` prohibiendo borrar roles base del sistema (`ADMIN`, `KITCHEN_STAFF`).
- `locations.controller.ts` & `stock.routes.ts`: `PUT /api/v1/locations/:id` y `DELETE /api/v1/locations/:id`.

### Frontend:
- `users.service.ts`: `updateUser(id, data)`
- `roles.service.ts`: `deleteRole(id)`
- `locations.service.ts`: `updateLocation(id, data)` y `deleteLocation(id)`
- `UserManagementPanel.tsx`: Tabla/lista de personal registrado con acciones de edición en tiempo real, cambio de rol y estado.
- `RolesManagementModal.tsx`: Acción de eliminación de roles personalizados.
- `LocationsManagementModal.tsx`: Acción de edición y eliminación de sectores físicos.

---

## ✅ Criterios de Aceptación & DoD
1. **Ver Personal Registrado y Editar**: El Super Admin consulta la lista completa de personal y puede cambiar el rol o datos de cualquier usuario.
2. **CRUD Completo de Roles**: El Super Admin puede crear, actualizar permisos y eliminar roles dinámicos.
3. **CRUD Completo de Sectores**: El Super Admin puede crear, editar y eliminar sectores de almacenamiento.
4. **Seguridad RBAC**: Únicamente el rol `ADMIN` puede ejecutar mutaciones en estos endpoints.
5. **Verificación Estricta**: `pnpm run build` y `pnpm test` aprueban al 100%.
