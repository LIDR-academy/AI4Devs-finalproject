## 📝 Descripción
Este ticket de base técnica configura el núcleo del backend monorepo en Node.js/TypeScript y la conexión con la base de datos PostgreSQL utilizando Prisma ORM. Define las bases arquitectónicas compartidas (Shared Kernel) requeridas por todos los slices verticales funcionales, incluyendo el middleware de validación genérico (Zod) y el bootstrap del servidor Express.

## 🔀 Alcance de Modificación (Hexagonal Layers)
*   **Domain:** Definición de la interfaz del logger del sistema, clases base de errores de dominio (ej. `DomainError`, `EntityNotFoundException`) y tipos comunes reutilizables.
*   **Application:** Interfaces de Casos de Uso genéricos.
*   **Infrastructure:** Configuración de la conexión del cliente de Prisma, middleware global de manejo de excepciones, middleware de validación Zod (`validation.middleware.ts`) y archivo de configuración segura de entorno (`environment.ts`).

---

## ⚠️ Mitigación de Riesgos Técnicos
1.  **Fuga de Conexiones a la BD (Connection Pool Exhaustion):** Para evitar el agotamiento de sockets en entornos Serverless o de rápido reinicio, inicializar el cliente Prisma como una instancia única (Singleton) y configurar el tamaño del pool según los recursos del contenedor.
2.  **Variables de Entorno Inválidas o Ausentes:** Utilizar Zod para validar `DATABASE_URL` y `JWT_SECRET` al arranque del proceso, impidiendo que el servidor inicie en un estado zombi o inconsistente.

---

## ✅ Criterios de Aceptación & DoD (Definition of Done)
1.  **DoD Técnico - Conectividad:** El cliente de Prisma debe poder inicializarse correctamente y establecer conexión cifrada con la base de datos de test efímera durante el proceso de pruebas.
2.  **DoD Técnico - Fail-Fast Config:** Si el servidor se inicia sin definir la variable de entorno `DATABASE_URL` o `JWT_SECRET`, el proceso debe interrumpirse inmediatamente lanzando un error descriptivo de validación Zod.
3.  **DoD Técnico - Puerto Express:** El servidor Express debe configurarse para escuchar en el puerto indicado por la variable de entorno `PORT`, cayendo en un valor por defecto de `3000` si esta no se encuentra definida.
4.  **DoD Seguridad:** Las consultas a través del cliente de Prisma no deben hacer uso de sentencias concatenadas de tipo raw (`queryRawUnsafe`).
5.  **DoD Compilación & Lint:** La ejecución de `pnpm run build` y `pnpm run lint` debe completarse con 0 errores en el módulo del backend.
6.  **DoD Plantillas e Infraestructura:** Creación obligatoria de las plantillas `.env.example`, archivos `.env` de desarrollo local tanto para `apps/backend/` como para `apps/frontend/`, y el archivo `docker-compose.yml` en la raíz para la base de datos PostgreSQL 15.
