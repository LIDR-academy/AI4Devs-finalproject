# Screenshots for the user guide

PNG captures embedded from [`../user-guide.md`](../user-guide.md).

## Naming

Keep sequential filenames already used in the guide (for example `01-login.png`, `04-book-tracker.png`).

## Tips

- Prefer desktop width (~1280–1440 px) unless documenting mobile.
- Use the demo account with seeded data (`lectora@example.com`) so charts and galleries look complete.
- Crop browser chrome if it distracts; keep the app sidebar visible when documenting navigation.
