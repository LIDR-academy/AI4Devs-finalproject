# Especificación API

## GET /health

Comprueba que el backend está operativo.

## POST /patients

Crea un paciente.

## GET /patients

Lista pacientes.

## POST /encounters

Crea un encuentro clínico.

## POST /encounters/{id}/extract-events

Extrae eventos clínicos desde una nota médica.

## GET /patients/{id}/timeline

Obtiene el timeline del paciente.
