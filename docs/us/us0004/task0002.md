# TASK0002 — Frontend: panel de filtros reactivo

## User Story Padre
[US0004](us0004.md) — Filtrar artistas por estilo, precio, rating y certificación

## Descripción
Implementar panel de filtros en la vitrina que actualiza resultados en tiempo real sin botón "Aplicar", con diseño responsive (sidebar desktop, bottom sheet mobile).

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/artists/components/filter-panel/`, `frontend/src/app/features/artists/services/artist-filter.service.ts`
- **Endpoint(s)**: Consume `GET /api/artists`

## Pasos Técnicos
1. Crear `ArtistFilterService`:
   - Signal `filters` con estado actual de todos los filtros
   - Método `updateFilter(key, value)` que emite cambio
   - Debounce de 300ms en slider de precio
   - Llama a GET /api/artists con filtros como query params
2. Crear `FilterPanelComponent` (standalone):
   - Checkboxes para estilos (cargados desde API o constantes)
   - Slider doble (Angular Material) para rango de precio
   - Rating selector (1-5 estrellas clickeables)
   - Toggle "Solo certificados"
   - Toggle "Con disponibilidad esta semana"
   - Radio buttons: Todos / Estudio / Independiente
3. Layout responsive:
   - Desktop: sidebar izquierdo sticky
   - Mobile: bottom sheet con botón flotante "Filtros" para abrir
4. Contador de resultados: "X artistas encontrados" (desde `total` del response)
5. Estado vacío: "No hay artistas con estos filtros. Intenta ampliar tu búsqueda."
6. Actualización reactiva: cada cambio de filtro dispara nueva consulta (con debounce en precio)
7. Tests:
   - Cambiar filtro dispara nueva consulta
   - Debounce en precio funciona (no dispara en cada pixel)
   - Estado vacío se muestra
   - Contador se actualiza

## Criterios de Done
- [ ] Filtros actualizan resultados en tiempo real
- [ ] Debounce 300ms en slider de precio
- [ ] Responsive: sidebar en desktop, bottom sheet en mobile
- [ ] Contador de resultados visible
- [ ] Mensaje de estado vacío con sugerencia
- [ ] Tests de componentes
- [ ] URL refleja filtros aplicados (query params sincronizados)
