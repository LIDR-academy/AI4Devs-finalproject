# TASK0001 — Backend: endpoint GET /api/artists con filtros combinados

## User Story Padre
[US0004](us0004.md) — Filtrar artistas por estilo, precio, rating y certificación

## Descripción
Implementar endpoint GET /api/artists con query params para filtrado combinado (AND lógico) por estilo, precio, rating, certificación, disponibilidad y tipo de artista.

## Detalles de Implementación
- **Capa**: Backend
- **Componentes afectados**: `backend/Controllers/ArtistsController.cs`, `backend/Domain/Services/ArtistQueryService.cs`
- **Endpoint(s)**: `GET /api/artists?style=&minPrice=&maxPrice=&minRating=&certified=&available=&type=&page=&pageSize=`

## Pasos Técnicos
1. Crear DTO `ArtistFilterRequest` con todos los query params (todos opcionales)
2. Implementar query builder dinámico con IQueryable:
   - `style`: filtrar por ArtistStyle.style_id matching slug
   - `minPrice/maxPrice`: filtrar por min_session_price
   - `minRating`: filtrar por rating_avg >=
   - `certified`: filtrar por existencia de Certification con is_active=true
   - `available`: join con Availability donde día actual tiene slots libres (no blocked, no booked)
   - `type`: filtrar por artist_type ('independent', 'studio')
3. Combinar filtros con AND lógico
4. Paginación: page (default 1), pageSize (default 12, max 50)
5. Respuesta: `{ data: ArtistCard[], total: int, page: int, pageSize: int }`
6. Índices requeridos ya creados en TASK0001 de US0001
7. Tests TDD:
   - Sin filtros: retorna todos publicados paginados
   - Filtro por estilo: solo artistas con ese estilo
   - Filtro por precio: rango correcto
   - Filtro certified: solo con certificación activa
   - Combinación de filtros (AND)
   - Paginación correcta (total, page, pageSize)
   - pageSize > 50 se limita a 50

## Criterios de Done
- [ ] Endpoint público retorna artistas filtrados
- [ ] Todos los filtros funcionan individualmente y combinados
- [ ] Paginación correcta con total count
- [ ] Solo artistas publicados
- [ ] Tests TDD: unitarios para cada filtro + combinaciones
- [ ] Query optimizada (no N+1, includes necesarios)
- [ ] Validación de inputs (rangos válidos)
