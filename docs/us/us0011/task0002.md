# TASK0002 — Frontend: chatbot wizard conversacional

## User Story Padre
[US0011](us0011.md) — Cotizar tatuaje con chatbot conversacional

## Descripción
Implementar componente de chat con flujo guiado de 5 pasos para cotizar un tatuaje, con UI conversacional y cálculo en tiempo real.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/quote-chatbot/`
- **Endpoint(s)**: Consume `POST /api/quotes/calculate`

## Pasos Técnicos
1. Crear `QuoteChatbotComponent` (overlay/dialog desde perfil):
   - Estado: step actual (1-5), respuestas acumuladas
   - UI tipo chat: mensajes del bot + respuestas del usuario
2. Pasos:
   - Paso 1: Zona del cuerpo → selector con silueta o dropdown
   - Paso 2: Tamaño → opciones visuales (moneda/palma/mano/brazo)
   - Paso 3: Estilo → galería con estilos del artista (solo los que maneja)
   - Paso 4: Imágenes referencia → upload opcional (1-3 fotos a S3)
   - Paso 5: Color/B&N + Cover-up → toggles
3. Post-paso 5:
   - Llama POST /api/quotes/calculate
   - Muestra rango: "$X - $Y CLP"
   - CTA: "¿Quieres reservar?" → navega a calendario (US0008) con datos pre-cargados
4. Navegación: botón "← Atrás" en cada paso
5. Si autenticado: guardar cotización en localStorage (asociar a booking si reserva)
6. Tests:
   - Navega entre pasos
   - Botón atrás funciona
   - Calcula precio al completar 5 pasos
   - CTA reservar navega con parámetros

## Criterios de Done
- [ ] 5 pasos conversacionales funcionales
- [ ] Navegación adelante/atrás
- [ ] Cálculo de precio mostrado al final
- [ ] CTA "Reservar" conecta con flujo US0008
- [ ] Upload de imágenes funcional (opcional)
- [ ] Tests de componente
- [ ] UI responsive (mobile-first: fullscreen)

## Estimación
- Tiempo estimado: 6 horas
- Complejidad: Alta
