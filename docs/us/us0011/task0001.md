# TASK0001 — Backend: endpoint POST /api/quotes/calculate

## User Story Padre
[US0011](us0011.md) — Cotizar tatuaje con chatbot conversacional

## Descripción
Implementar endpoint de cálculo de cotización basado en tarifas del artista y factores de complejidad.

## Detalles de Implementación
- **Capa**: Backend
- **Componentes afectados**: `backend/Controllers/QuotesController.cs`, `backend/Domain/Services/QuoteCalculatorService.cs`
- **Endpoint(s)**: `POST /api/quotes/calculate`

## Pasos Técnicos
1. Crear DTO `QuoteRequest`: { artistProfileId, bodyZone, size (small/medium/large/xlarge), styleId, isColor, isCoverup }
2. Crear DTO `QuoteResponse`: { minPrice, maxPrice, currency: "CLP", factors: string[] }
3. Implementar `QuoteCalculatorService`:
   - Base = max(artist.min_session_price, artist.hourly_rate × estimated_hours)
   - estimated_hours por tamaño: small=1, medium=2, large=4, xlarge=6
   - Factores multiplicadores:
     - Cover-up: +30%
     - Color: +20%
     - Zona difícil (costillas, cuello, manos): +15%
   - Rango: [base × 0.8, base × 1.3]
4. Validaciones:
   - Artist debe existir y estar publicado
   - Size debe ser valor válido
   - Style debe existir
5. Tests TDD:
   - Cálculo base correcto
   - Factor cover-up aplica +30%
   - Factor color aplica +20%
   - Factores se acumulan multiplicativamente
   - Artista no publicado → 404
   - Retorna factors aplicados en response

## Criterios de Done
- [ ] Endpoint retorna rango de precio correcto
- [ ] Factores de complejidad aplicados correctamente
- [ ] Validaciones de input
- [ ] Tests TDD
- [ ] No requiere autenticación (público)
