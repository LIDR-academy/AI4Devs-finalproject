# US0011 — Cotizar tatuaje con chatbot conversacional

## Descripción
**Como** visitante o cliente
**Quiero** interactuar con un chatbot que me guíe paso a paso para estimar el precio de un tatuaje
**Para** obtener un rango de precio inmediato sin esperar respuesta del artista por DM

## Criterios de Aceptación

- [x] CA1: Desde el perfil del artista, existe botón "Cotizar" que abre el chatbot
- [x] CA2: El chatbot realiza 5 preguntas en secuencia conversacional:
  - Paso 1: "¿En qué zona del cuerpo?" — silueta interactiva o selector
  - Paso 2: "¿Qué tamaño aproximado?" — opciones visuales (moneda/palma/mano/brazo)
  - Paso 3: "¿Qué estilo te interesa?" — galería con estilos del artista
  - Paso 4: "¿Tienes imágenes de referencia?" — upload 1-3 fotos (opcional)
  - Paso 5: "¿Color o B&N? ¿Es cover-up?" — toggles
- [x] CA3: Al completar las 5 preguntas, el chatbot muestra rango de precio estimado (ej: "$80.000 - $150.000 CLP")
- [x] CA4: El cálculo usa las tarifas del artista (min_session_price, hourly_rate) + factores de complejidad (tamaño, estilo, color, cover-up)
- [x] CA5: Después del precio, el chatbot ofrece CTA "¿Quieres reservar?" que lleva directamente a selección de slot (US0008)
- [x] CA6: El cliente puede volver atrás en cualquier paso para ajustar respuestas
- [x] CA7: Si el cliente no quiere reservar ahora, la cotización queda guardada (si está autenticado)
- [x] CA8: Los datos del chatbot (zona, tamaño, estilo, color, cover-up) se pasan al booking si reserva — ⚠️ las imágenes de referencia solo tienen preview local: el upload a Object Storage sigue pendiente (misma limitación mock-first que `fixs/issue-005.md`)
- [x] CA9: Si la reserva se origina en una cotización, el booking hereda el rango estimado y el depósito se calcula como deposit_percentage × máx(mínimo cotizado, min_session_price); sin cotización, se mantiene el fallback 30% × min_session_price (decisión `fixs/issue-007.md`)

## Notas Técnicas
- Frontend: componente de chat con pasos guiados (no IA generativa — flujo determinístico)
- Backend: POST /api/quotes/calculate con body {artist_id, body_zone, size, style_id, is_color, is_coverup}
- Fórmula de pricing: base = max(min_session_price, hourly_rate x estimated_hours); rango = base x [0.8, 1.3] ajustado por factores
- Factores de complejidad: cover-up +30%, color +20%, zona difícil +15%
- La fórmula vive en un único servicio (QuoteCalculatorService) reutilizado por POST /api/quotes/calculate y por POST /api/bookings/hold (CA9): el hold recalcula la cotización server-side, nunca acepta montos del cliente
- Las imágenes de referencia se suben a Object Storage y se asocian al booking si se concreta
- El chatbot no usa IA generativa — es un wizard conversacional con UI de chat
