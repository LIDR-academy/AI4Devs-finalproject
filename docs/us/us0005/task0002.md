# TASK0002 — Frontend: barra de búsqueda con autocompletado

## User Story Padre
[US0005](us0005.md) — Buscar artistas por texto

## Descripción
Implementar barra de búsqueda prominente con debounce, autocompletado de estilos/comunas y combinación con filtros activos.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/artists/components/search-bar/`
- **Endpoint(s)**: Consume `GET /api/artists?search=` y `GET /api/artists/suggestions?q=`

## Pasos Técnicos
1. Crear `SearchBarComponent` (standalone):
   - Input con ícono de búsqueda, prominente en header de vitrina
   - Debounce 300ms con rxjs `debounceTime`
   - Emite búsqueda a partir de 2 caracteres
2. Panel de sugerencias (dropdown):
   - Consume /api/artists/suggestions
   - Muestra estilos y comunas que matchean
   - Click en sugerencia aplica como filtro
3. Integrar con `ArtistFilterService`:
   - El texto de búsqueda se agrega a los filtros activos
   - Limpieza con botón "X" en el input
4. Estado sin resultados: "No encontramos artistas para '[búsqueda]'" con CTA "Limpiar filtros"
5. Tests:
   - No busca con 0-1 caracteres
   - Busca a partir de 2 caracteres
   - Debounce funciona
   - Sugerencias se muestran
   - Limpieza del campo resetea búsqueda

## Criterios de Done
- [ ] Búsqueda funciona a partir de 2 caracteres
- [ ] Debounce 300ms
- [ ] Autocompletado con estilos y comunas
- [ ] Se combina con filtros activos
- [ ] Mensaje sin resultados con CTA limpiar
- [ ] Tests de componente
- [ ] Accesible (aria-labels, keyboard navigation en sugerencias)

## Estimación
- Tiempo estimado: 2 horas
- Complejidad: Baja
