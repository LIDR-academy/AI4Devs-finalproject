# TASK0001 — Migración base de datos: esquema completo

## User Story Padre
[US0001](us0001.md) — Inicio de sesión de usuarios

## Descripción
Crear la migración EF Core con todas las entidades del modelo de datos INK·LINK y seed de datos inicial para desarrollo.

## Detalles de Implementación
- **Capa**: Base de Datos + Backend
- **Componentes afectados**: `backend/Domain/Entities/`, `backend/Infrastructure/Data/`, `backend/Migrations/`, `backend/Seed/`
- **Endpoint(s)**: N/A

## Pasos Técnicos
1. Crear entidades C# con data annotations y Fluent API:
   - User, ArtistProfile, PortfolioItem, TattooStyle, ArtistStyle, Availability, BlockedDate, Booking, Payment, Review, Certification, Award, Sponsorship
2. Configurar DbContext con relaciones, índices y constraints
3. Índices requeridos: User.email (unique), ArtistProfile.slug (unique), ArtistProfile.commune, ArtistProfile.is_published, ArtistProfile.rating_avg, Booking.booking_date, Booking.status, Certification.is_active, Review.booking_id (unique)
4. Configurar PostgreSQL con JSONB para Booking.reference_images
5. Crear migración: `dotnet ef migrations add InitialSchema`
6. Crear seed data:
   - 3 users rol client, 5 users rol artist, 1 user admin (passwords bcrypt hash de "Test1234!")
   - 5 ArtistProfile con datos realistas de Santiago (coordenadas reales, comunas: Providencia, Ñuñoa, Santiago Centro, Las Condes, Vitacura)
   - 12 TattooStyle del catálogo
   - Portfolio items, estilos asociados, availability, certifications, awards, sponsorships para cada artista
7. Test de integración con TestContainers PostgreSQL: verificar migración + seed + consultas básicas

## Criterios de Done
- [ ] Código compilando sin errores
- [ ] Migración aplicable con `dotnet ef database update`
- [ ] Seed inserta datos completos y coherentes
- [ ] Test de integración: migración se aplica, seed se ejecuta, query por email retorna usuario
- [ ] Contraseñas NUNCA en texto plano (bcrypt hash)
- [ ] UUIDs generados server-side
- [ ] TIMESTAMPTZ para todos los timestamps
- [ ] JSONB para reference_images
- [ ] Enums almacenados como VARCHAR con validación en capa de aplicación
