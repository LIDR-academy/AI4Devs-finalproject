# TASK0003 — Frontend: página de login + guard de rutas + interceptor JWT

## User Story Padre
[US0001](us0001.md) — Inicio de sesión de usuarios

## Descripción
Implementar formulario de login, AuthGuard para rutas protegidas e interceptor HTTP que adjunta el token JWT a cada request.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/auth/`, `frontend/src/app/core/guards/`, `frontend/src/app/core/interceptors/`
- **Endpoint(s)**: Consume `POST /api/auth/login`

## Pasos Técnicos
1. Crear `AuthService` (Angular):
   - `login(email, password): Observable<LoginResponse>`
   - `logout()`: eliminar token de localStorage, redirigir a /login
   - `isAuthenticated(): boolean` (signal)
   - `currentUser(): UserSummary | null` (signal)
   - `getToken(): string | null`
2. Crear componente `LoginComponent` (standalone):
   - Formulario reactivo con email + password
   - Validaciones: email requerido + formato, password requerido
   - Mensaje de error genérico en UI
   - Redirect a ruta previa o home post-login
3. Crear `AuthGuard` (functional guard):
   - Si no autenticado → redirect a /login con returnUrl
4. Crear `AuthInterceptor` (HttpInterceptorFn):
   - Adjuntar header `Authorization: Bearer <token>` a requests al API
   - Si response 401 → logout y redirect a login
5. Configurar rutas: /login público, rutas protegidas con canActivate
6. Almacenar token en localStorage (aceptable para MVP)
7. Tests unitarios:
   - AuthService: login exitoso guarda token, logout limpia
   - AuthGuard: redirige si no hay token
   - LoginComponent: muestra error en credenciales inválidas

## Criterios de Done
- [ ] Formulario de login funcional con validaciones
- [ ] Error genérico visible al fallar autenticación
- [ ] Guard protege rutas correctamente
- [ ] Interceptor adjunta token a cada request
- [ ] Logout limpia estado y redirige
- [ ] Tests unitarios para AuthService, Guard y Component
- [ ] No se almacena password en ningún momento en frontend
- [ ] UI responsive (mobile-first, Angular Material)
