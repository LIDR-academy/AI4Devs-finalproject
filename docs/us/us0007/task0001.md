# TASK0001 — Frontend: componente CertificationBadge reutilizable

## User Story Padre
[US0007](us0007.md) — Badge de certificación sanitaria

## Descripción
Crear componente Angular standalone reutilizable que muestra el badge "Certificado" cuando un artista tiene certificación sanitaria activa.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/shared/components/certification-badge/`
- **Endpoint(s)**: N/A (usa datos ya presentes en ArtistCard/ArtistDetail)

## Pasos Técnicos
1. Crear `CertificationBadgeComponent` (standalone):
   - Input: `isCertified: boolean`
   - Si true: renderiza badge con ícono ✓ + texto "Certificado"
   - Si false: no renderiza nada (ngIf, sin espacio vacío)
   - Variante `size`: 'sm' (para cards) | 'md' (para perfil)
2. Estilos:
   - Background verde suave, borde, ícono check
   - Diseño reconocible y consistente
   - Tailwind classes reutilizables
3. Integrar en:
   - `ArtistCard` component (usado en vitrina y búsqueda)
   - `ArtistProfilePage` (header del perfil)
4. Tests:
   - Renderiza badge si isCertified=true
   - No renderiza nada si isCertified=false
   - Variante sm y md tienen tamaños diferentes
5. Accesibilidad: aria-label "Artista con certificación sanitaria vigente"

## Criterios de Done
- [ ] Componente standalone reutilizable
- [ ] Se muestra en cards de vitrina y perfil de artista
- [ ] No se muestra si no tiene certificación (sin espacio vacío)
- [ ] Diseño reconocible y consistente
- [ ] Tests unitarios
- [ ] Accesible (aria-label)

- Tiempo estimado: 1 hora
- Complejidad: Baja
