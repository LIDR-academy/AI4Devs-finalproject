# TASK0002 — Frontend: calendario semanal + resumen de reserva

## User Story Padre
[US0008](us0008.md) — Seleccionar slot disponible y ver resumen de reserva

## Descripción
Implementar componente de calendario semanal interactivo y pantalla de resumen de reserva con countdown de 5 minutos.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/booking/components/`
- **Endpoint(s)**: Consume availability y hold endpoints

## Pasos Técnicos
1. Crear `WeeklyCalendarComponent`:
   - Vista semanal con navegación (← semana anterior | semana siguiente →)
   - Slots como botones: verde=disponible, gris=ocupado/bloqueado
   - Click en slot disponible → seleccionar
   - Solo permite navegar a futuro (no semanas pasadas)
2. Crear `BookingSummaryComponent`:
   - Muestra: nombre artista, fecha, hora, duración estimada, precio estimado (min-max), monto depósito
   - Countdown de 5 minutos (timer visual)
   - Botón "Pagar depósito" → navega a US0009
   - Si countdown llega a 0: muestra "Tiempo expirado" y libera slot
3. Flujo:
   - Si no autenticado al seleccionar slot → redirect login con returnUrl
   - Post-login: retorna al perfil con slot pre-seleccionado
   - Al seleccionar: llama POST /api/bookings/hold
   - Si 409 (slot tomado): mostrar toast "Este horario ya fue reservado"
4. Tests:
   - Calendario muestra slots correctos
   - Slot ocupado no es clickeable
   - Selección dispara llamada hold
   - Countdown funciona y expira
   - Redirect a login si no autenticado

## Criterios de Done
- [ ] Calendario semanal interactivo funcional
- [ ] Slots disponibles vs ocupados distinguibles visualmente
- [ ] Resumen muestra datos correctos con depósito calculado
- [ ] Countdown de 5 minutos funcional
- [ ] Redirect a login si no autenticado
- [ ] Manejo de error 409 (slot ya tomado)
- [ ] Tests de componentes
- [ ] Responsive
