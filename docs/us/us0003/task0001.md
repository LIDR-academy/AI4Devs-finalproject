# TASK0001 — Backend: endpoint GET /api/showcase

## User Story Padre
[US0003](us0003.md) — Ver vitrina principal de tatuajes sin login

## Descripción
Implementar endpoint que retorna artistas agrupados por secciones (Cerca de ti, Mejor calificados, Estilos populares, Artistas premiados) con soporte de geolocalización PostGIS.

## Detalles de Implementación
- **Capa**: Backend
- **Componentes afectados**: `backend/Controllers/ShowcaseController.cs`, `backend/Domain/Services/ShowcaseService.cs`, `backend/Infrastructure/Repositories/ArtistRepository.cs`
- **Endpoint(s)**: `GET /api/showcase?lat={lat}&lng={lng}`

## Pasos Técnicos
1. Crear DTO `ShowcaseResponse` con secciones:
   - nearYou: ArtistCard[] (por distancia PostGIS, máx 8)
   - topRated: ArtistCard[] (por rating_avg desc, máx 8)
   - popularStyles: {styleName, artists: ArtistCard[]}[] (top 4 estilos con más artistas)
   - awardWinners: ArtistCard[] (artistas con al menos 1 award, máx 8)
2. Crear DTO `ArtistCard`: id, artistName, slug, profilePhotoUrl, bio(truncado 100 chars), styles[], city, latitude, longitude, minPrice, maxPrice, isCertified, averageRating, reviewCount
3. Implementar query PostGIS para "Cerca de ti":
   - `ST_DWithin(geography, point, radius_meters)` ordenado por distancia
   - Si no se envía lat/lng → retornar por rating
4. Filtrar solo artistas con `is_published = true`
5. Incluir campo `isCertified` (existe Certification con is_active=true)
6. Tests unitarios (TDD):
   - Sin coordenadas: retorna todos por rating
   - Con coordenadas: sección nearYou ordenada por distancia
   - Solo artistas publicados aparecen
   - ArtistCard tiene todos los campos esperados
7. Test de integración con PostGIS:
   - Seed 5 artistas con coordenadas de Santiago
   - Verificar orden por distancia desde punto central

## Criterios de Done
- [ ] Endpoint público (sin auth) retorna 200 con 4 secciones
- [ ] Sección "Cerca de ti" usa PostGIS si hay coordenadas
- [ ] Solo artistas publicados
- [ ] Cada card incluye isCertified calculado
- [ ] Tests TDD: unitarios + integración con PostGIS
- [ ] Response time < 500ms con datos seed
- [ ] No expone información sensible (emails, phones)
