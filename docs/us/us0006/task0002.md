# TASK0002 — Frontend: página de perfil de artista

## User Story Padre
[US0006](us0006.md) — Ver perfil de artista con portafolio, tarifas y certificaciones

## Descripción
Implementar página pública del perfil del artista con portafolio, tarifas, badges, reviews y calendario de disponibilidad.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/artist-profile/`
- **Endpoint(s)**: Consume `GET /api/artists/{slug}` y `GET /api/artists/{slug}/reviews`

## Pasos Técnicos
1. Crear ruta `/artista/:slug` pública (sin guard)
2. Crear `ArtistProfilePage`:
   - Header: foto, nombre, bio, años experiencia, tipo, comuna
   - Sección estilos: tags/badges
   - Sección portafolio: grid de imágenes con lightbox (Angular CDK overlay o library)
   - Sección tarifas: precio mínimo sesión + precio por hora (CLP formateado)
   - Sección certificaciones: badges (componente US0007)
   - Sección premios: lista con badge_icon + título + evento + año
   - Sección reviews: paginadas, rating por dimensión
   - Mini-mapa: Leaflet con marcador de ubicación
   - CTAs: "Cotizar" y "Reservar" (sticky en mobile)
3. Crear `PortfolioGalleryComponent`: grid con lightbox
4. Crear `ReviewListComponent`: cards con estrellas por dimensión
5. Crear `AvailabilityCalendarComponent`: vista semanal simple (preview, detalle en US0008)
6. Layout responsive:
   - Mobile: secciones apiladas, CTAs sticky bottom
   - Desktop: layout 2 columnas (info + portafolio lado a lado)
7. Tests:
   - Renderiza datos del artista correctamente
   - Lightbox abre al click en imagen
   - Reviews paginadas (load more)
   - 404 page si artista no existe

## Criterios de Done
- [ ] Perfil muestra toda la información del artista
- [ ] Portafolio con lightbox funcional
- [ ] Reviews paginadas
- [ ] Mini-mapa con ubicación
- [ ] CTAs visibles y funcionales
- [ ] Responsive mobile-first
- [ ] SEO: meta tags dinámicos con nombre del artista
- [ ] Tests de componentes

- Tiempo estimado: 5 horas
- Complejidad: Media
