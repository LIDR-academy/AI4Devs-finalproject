# TASK0001 — Frontend: sección de auspicios en perfil de artista

## User Story Padre
[US0014](us0014.md) — Mostrar auspicios de marcas en perfil de artista

## Descripción
Implementar sección "Auspiciado por" en el perfil del artista y badges de marca en cards de vitrina.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/artist-profile/components/sponsorship-section/`, `frontend/src/app/shared/components/artist-card/`
- **Endpoint(s)**: Datos ya incluidos en `GET /api/artists/{slug}` (sponsorships[])

## Pasos Técnicos
1. Crear `SponsorshipSectionComponent`:
   - Título: "Auspiciado por"
   - Grid de logos de marca con nombre y tipo de relación
   - Tipo renderizado como badge: "Embajador" / "Auspiciado" / "Certificado"
   - Solo se muestra si sponsorships.length > 0
2. Crear `SponsorBadgeComponent` (para cards de vitrina):
   - Mini-logos de marcas (máx 3 visibles + "+N más")
   - Visible en ArtistCard de la vitrina (US0003)
3. Integrar en ArtistProfilePage:
   - Después de sección premios
   - Conditional rendering: solo si hay datos
4. Tests:
   - Sección no se muestra si no hay sponsors
   - Logos y nombres renderizados
   - Tipo de relación con badge correcto
   - Cards muestran mini-badges de marcas

## Criterios de Done
- [x] Sección visible solo si artista tiene sponsors
- [x] Logo + nombre + tipo de relación mostrados
- [x] Badges en cards de vitrina
- [x] Conditional rendering correcto
- [x] Tests de componente
- [x] Imágenes con fallback si logo no carga

## Estimación
- Tiempo estimado: 2 horas
- Complejidad: Baja
