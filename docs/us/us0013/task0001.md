# TASK0001 — Backend: endpoint POST /api/reviews + recalcular rating

## User Story Padre
[US0013](us0013.md) — Calificar artista post-sesión

## Descripción
Implementar endpoint para crear reviews con 4 dimensiones, validaciones de negocio y recálculo automático del rating promedio del artista.

## Detalles de Implementación
- **Capa**: Backend
- **Componentes afectados**: `backend/Controllers/ReviewsController.cs`, `backend/Domain/Services/ReviewService.cs`
- **Endpoint(s)**: `POST /api/reviews` (autenticado)

## Pasos Técnicos
1. Crear DTO `CreateReviewRequest`:
   - bookingId (required), ratingHygiene (1-5), ratingPainManagement (1-5), ratingCustomerService (1-5), ratingResult (1-5), comment (optional, max 2000), tattooPhotoUrl (optional)
2. Validaciones de negocio:
   - Booking debe existir
   - Booking.client_id == usuario autenticado
   - Booking.status == 'completed'
   - No existe review previa para ese booking (unique constraint)
3. Crear Review con datos + calcular averageRating = (h+p+c+r)/4
4. Recalcular ArtistProfile:
   - rating_avg = promedio de todos los ratings de reviews del artista
   - total_reviews += 1
   - Usar query SQL para cálculo atómico (evitar race condition)
5. Retornar 201 con review creada
6. Tests TDD:
   - Review creada exitosamente con datos válidos
   - Rating del artista recalculado correctamente
   - Falla si booking no es del usuario (403)
   - Falla si booking no está completed (409)
   - Falla si ya existe review para ese booking (409)
   - Falla si ratings fuera de rango 1-5 (422)
   - Comment > 2000 chars rechazado (422)

## Criterios de Done
- [ ] Review se crea con 4 dimensiones
- [ ] Validaciones de negocio estrictas
- [ ] Rating del artista recalculado atómicamente
- [ ] Unique constraint previene duplicados
- [ ] Tests TDD
- [ ] No permite editar ni eliminar reviews (inmutables)
- [ ] Solo usuarios autenticados con booking completado
