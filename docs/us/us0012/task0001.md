# TASK0001 — Backend: endpoint GET /api/artists/geo con PostGIS

## User Story Padre
[US0012](us0012.md) — Explorar artistas en mapa interactivo

## Descripción
Implementar endpoint geoespacial que retorna artistas dentro de un radio usando PostGIS ST_DWithin.

## Detalles de Implementación
- **Capa**: Backend
- **Componentes afectados**: `backend/Controllers/ArtistsController.cs`, `backend/Domain/Services/GeoService.cs`
- **Endpoint(s)**: `GET /api/artists/geo?lat=&lng=&radius=`

## Pasos Técnicos
1. Endpoint GET /api/artists/geo:
   - Params: lat (required), lng (required), radius (km, default 10, max 50)
   - Query PostGIS: `ST_DWithin(geography(point(lng,lat)), geography(point(artist.lng, artist.lat)), radius_meters)`
   - Ordenar por distancia
   - Límite: max 100 artistas
   - Retorna: ArtistCard[] con lat/lng incluidos
2. Aplicar filtros de US0004 (style, price, certified, etc.) como params opcionales
3. Solo artistas publicados
4. Índice espacial ya configurado en migración
5. Tests TDD:
   - Retorna artistas dentro del radio
   - No retorna artistas fuera del radio
   - Límite de 100 respetado
   - Combinación con filtros funciona
   - Parámetros inválidos → 400

## Criterios de Done
- [ ] Endpoint retorna artistas por proximidad
- [ ] PostGIS usado para cálculo de distancia
- [ ] Límite de 100 artistas
- [ ] Combinable con filtros existentes
- [ ] Tests TDD
- [ ] Índice espacial para performance
