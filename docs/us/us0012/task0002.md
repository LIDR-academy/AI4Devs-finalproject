# TASK0002 — Frontend: vista mapa con Leaflet + marcadores

## User Story Padre
[US0012](us0012.md) — Explorar artistas en mapa interactivo

## Descripción
Implementar vista de mapa interactivo con Leaflet + OpenStreetMap, marcadores de artistas con clustering y preview cards.

## Detalles de Implementación
- **Capa**: Frontend
- **Componentes afectados**: `frontend/src/app/features/map/`
- **Endpoint(s)**: Consume `GET /api/artists/geo`

## Pasos Técnicos
1. Instalar: leaflet, @types/leaflet, leaflet.markercluster
2. Crear `MapViewPage` (ruta: /mapa):
   - Al cargar: solicitar geolocalización
   - Si acepta: centrar mapa en posición del usuario
   - Si rechaza: centrar en Santiago (-33.4489, -70.6693)
3. Crear `ArtistMapComponent`:
   - Mapa Leaflet con tiles OpenStreetMap
   - Marcadores de artistas con clustering (MarkerClusterGroup)
   - Marcadores con foto thumbnail como ícono custom
4. Radio configurable: botones 1km/5km/10km/toda la ciudad
   - Al cambiar radio: re-fetch /api/artists/geo con nuevo radius
5. Preview card al click en marcador:
   - Popup Leaflet custom con: foto, nombre, rating, estilo, comuna
   - CTAs: "Ver perfil" y "Cotizar"
6. Toggle vista mapa ↔ lista (reutilizar grid de cards de US0003)
7. Integrar filtros de US0004 (mismo FilterPanelComponent)
8. Tests:
   - Mapa renderiza
   - Marcadores se muestran
   - Cambio de radio dispara nueva query
   - Preview card muestra datos correctos

## Criterios de Done
- [ ] Mapa interactivo con Leaflet + OSM
- [ ] Marcadores con clustering
- [ ] Geolocalización del usuario
- [ ] Radio configurable
- [ ] Preview card al click
- [ ] Toggle mapa/lista
- [ ] Filtros integrados
- [ ] Tests de componente
- [ ] Performance OK con 100 marcadores
