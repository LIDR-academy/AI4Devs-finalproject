# [C1] T-C1-78 · SLA-threshold escalation as a system-actor action, idempotent per threshold

## Context

`US-C1-26` draws the boundary explicitly: when an SLA warning or breach event raised by `C7` / `C12` reaches the Incident, it performs the configured escalation as a **system-actor action** recording the triggering threshold — and **C1 owns the escalation action; raising the threshold event belongs to `FR-SLA-07` and `FR-WFL-05` and is not written here**. The actor must be the system rule, **never a person** (`FR-AUD-02`), so manual and automatic escalations stay distinguishable in reporting. Repeated threshold events must not escalate twice for a threshold already escalated, so a retrying dispatcher cannot spam management.

**Boundary with `T-C1-45`.** This is an automated path. It performs an escalation and it must **never** touch the competition-in-progress flag; `T-C1-45` asserts exactly that against this handler.

## Scope

- Inbound handler in `libs/incident/application` consuming the SLA threshold event shape and performing the configured escalation.
- System-actor attribution per `FR-AUD-02`, distinguishable in the event and in the history from a human escalation.
- Idempotence keyed by Incident and threshold: a repeat for an already-escalated threshold is a no-op that is itself observable, not a silent swallow.
- The triggering threshold recorded on the escalation.
- Out of scope: raising the threshold event (`C7` `FR-SLA-07`, `C12` `FR-WFL-05`); the escalation-policy configuration surface if it belongs to `C12`; any flag write, which is forbidden.

## Acceptance criteria

**Given** an SLA warning or breach event for an Incident **When** it is handled **Then** the configured escalation is performed, the actor is the system rule, and the triggering threshold is recorded.

**Given** the same threshold event delivered three times **When** each is handled **Then** exactly one escalation exists, and the second and third are recorded as ignored duplicates rather than silently dropped.

**Given** a warning threshold followed by a breach threshold **When** both are handled **Then** two escalations occur, because they are different thresholds.

**Given** an automatic and a manual escalation on the same Incident **When** reporting reads them **Then** the actors distinguish them without inspecting free text.

**Given** this handler **When** the caller enumeration of `T-C1-45` runs **Then** it reaches no competition-in-progress flag mutator.
