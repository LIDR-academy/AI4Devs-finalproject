# [C1] T-C1-57 · Clock pause and resume signals, with per-state pause-behavior configuration

## Context

`US-C1-17` requires an Incident entering a `Pending` state **configured as clock-stopping** to publish a pause signal carrying the state, the reason and the `ClockPort` timestamp, and to publish a resume signal of the same shape on leaving it — while a `Pending` state configured as **not** clock-stopping publishes nothing and the clock keeps running.

**The boundary this ticket must not cross.** `incident` **never imports** `sla` (`ARCHITECTURE.md` §8, and the `scope:` rule the probe in `T-C1-01` proves). This ticket publishes **signals**. The adapter that turns them into SLA calls lives in `apps/api` (`T-C1-58`), and the clock arithmetic itself is `C7` (`FR-SLA-*`) and is **not written in this epic**.

## Scope

- `IncidentClockPaused` and `IncidentClockResumed` domain events carrying the state, the reason and a persisted UTC timestamp from `ClockPort` (ADR-009).
- Per-`Pending`-state pause-behavior configuration: entity, mapper, migration and seed, following the configuration-as-data pattern of `T-C1-50`.
- Emission wired into the transition path of `T-C1-51`, so no route can change state without the signal being considered.
- Both endpoints persisted as events, so elapsed pause is derivable after a process restart rather than held in memory.
- Out of scope: the `SlaPolicyAdapter` (`T-C1-58`); any SLA computation, which is `C7`; any import of `libs/sla/*`.

## Acceptance criteria

**Given** an Incident entering a `Pending` state configured as clock-stopping **When** the transition commits **Then** exactly one pause signal is published carrying the state, the reason and the UTC timestamp.

**Given** the Incident leaving that state **When** the transition commits **Then** exactly one resume signal of the same shape is published.

**Given** a `Pending` state configured as not clock-stopping **When** the Incident enters and leaves it **Then** no pause or resume signal is published.

**Given** a process restart between pause and resume **When** the Incident resumes **Then** the elapsed pause is derivable from the two persisted events with no reliance on in-memory state.

**Given** the `incident` libraries **When** lint and the dependency graph are checked **Then** no project imports anything under `libs/sla/`.
