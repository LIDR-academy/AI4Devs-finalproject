# [C1] T-C1-16 · Competition subject picker with an explicit unresolved-reference mode

## Context

`US-C1-03` requires an agent to name exactly which fixture, result or standings entry is affected, and requires the surface to keep working when SCMS reference data is unreachable — falling back to free text while showing that the reference is unresolved (`T-C1-15`).

**Blocked by finding F29.** This picker is placed on the **agent** surface only, per this backlog reading of `FR-INC-01`. If the Product Owner confirms that requesters may also set a structured subject, the same component is added to `T-C1-10` and the permission gate changes; the component itself does not.

## Scope

- Subject-type selector over the twelve stable identifiers of `T-C1-14`, labels through Transloco, in `libs/incident/ui` with no injected service.
- Instance search wired through `incident/data-access`, with loading, empty and error states always defined.
- Explicit degraded mode: when the lookup is unavailable, a free-text instance entry appears with a visible, announced statement that the reference will be recorded as unresolved.
- Keyboard-operable combobox with correct ARIA roles and states, hand-written, WCAG 2.1 AA.
- Out of scope: the lookup port and adapters (`T-C1-15`); the subject value object (`T-C1-14`).

## Acceptance criteria

**Given** the picker with the lookup available **When** an agent selects a subject type and searches an instance **Then** the selection is bound to the form and both parts are announced to a screen reader.

**Given** the lookup unavailable **When** the picker renders **Then** the free-text mode appears, states that the reference will be unresolved, and submission remains possible.

**Given** the component **When** it is inspected **Then** it lives in a `type:ui` library with no injected service, no store and no `HttpClient`, per the §5.3 matrix and the frontend rules of `CLAUDE.md` §3.

**Given** a keyboard-only user **When** they operate the picker **Then** the listbox is navigable, the active option is announced, and Escape returns focus to the trigger.
