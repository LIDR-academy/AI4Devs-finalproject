# [C1] T-C1-08 · Intake contracts and server-side rejection of priority-bearing fields

## Context

`US-C1-01` requires the requester intake surface to expose **no** priority-bearing field — no Impact, no Urgency, no Priority, no competition-in-progress flag — and requires the **server** to reject those fields when they appear in the request body, regardless of what the client sent (`NFR-SEC-02`). UI concealment is not the control.

`ARCHITECTURE.md` §6.3 already configures the global `ValidationPipe` with `whitelist`, `forbidNonWhitelisted` and `transform` in `apps/api` (`T-C10-04`); this ticket declares the DTOs that make that configuration bite for Incident intake, and the controller that consumes them. ADR-007 makes `libs/shared/contracts` the only FE/BE coupling.

## Scope

- Request and response DTOs for requester intake in `libs/shared/contracts`, validated with `class-validator`, with field-level messages resolved through `nestjs-i18n` on the API and Transloco on the client.
- `IncidentController` POST route in `apps/api` mapping the DTO to the use-case command.
- Explicit assertion that the requester DTO declares none of Impact, Urgency, Priority or the competition flag, so `forbidNonWhitelisted` rejects them.
- Typed domain errors mapped to contract error codes by the exception filter established in `T-C10-40`.
- Out of scope: the agent intake contract (`T-C1-11`); the flag rejection proof across every path (`T-C1-44`), which extends this one to update routes.

## Acceptance criteria

**Given** a requester intake request whose body contains an Impact, an Urgency, a Priority or the competition-in-progress flag **When** it is posted **Then** the response is a validation failure, no Incident is created, and the outcome is identical for each of the four fields.

**Given** a request missing a mandatory field **When** it is posted **Then** the response names the field and states what to do next, resolved in the language of the `Accept-Language` header (`NFR-USE-05`).

**Given** a valid request **When** it is posted **Then** the response is `201` with the reference number, and the body carries no field the requester is not permitted to see.

**Given** the contracts library **When** it is inspected **Then** it imports nothing from the `incident` domain, application or infrastructure libraries.
