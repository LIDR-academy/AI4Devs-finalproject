# [C1] T-C1-05 · `Incident` aggregate root and its creation invariants

## Context

`US-C1-01` requires an Incident created from the portal to capture reporter, contact channel, short description, detailed description and affected service, with the reporter taken from the authenticated session and never from a typed field. `ARCHITECTURE.md` §6.2 gives the aggregate shape and states that **every mutating method returns domain events** — audit-trail completeness by construction.

This is the core aggregate of the product; every later block extends it. It is built pure: no framework, no ORM, and no `new Date()` — time comes from `ClockPort` (`C10`, ADR-009).

## Scope

- `Incident` aggregate root in `libs/incident/domain` with the fields of `US-C1-01` plus its `TicketReference`, and a `log()` factory enforcing the creation invariants.
- Mandatory-field invariants raised as **typed domain errors**, never generic exceptions.
- `IncidentLogged` domain event returned from `log()`, carrying the actor, the reporter and the created state.
- Fields introduced by later blocks — category, assessed Impact, Urgency, derived Priority, competition flag, affected subject, assignment — declared absent by default, so later tickets add behavior rather than reshaping the aggregate.
- Out of scope: persistence (`T-C1-06`); the use case and authorization (`T-C1-07`); the competition subject value object (`T-C1-14`); all priority behavior (block D).

## Acceptance criteria

**Given** a valid command **When** `Incident.log()` executes **Then** an Incident is returned carrying reporter, contact channel, short description, detailed description, affected service and its reference, together with exactly one `IncidentLogged` event.

**Given** a command missing any mandatory field **When** `log()` executes **Then** a typed domain error names the missing field, and no Incident and no event is produced.

**Given** a newly logged Incident **When** it is read **Then** Priority is explicitly not yet derived, the competition-in-progress flag is unset, and no category is set — creation succeeds without one, because categorization is a triage responsibility gated at exit from New (`US-C1-07`).

**Given** the domain library **When** it is inspected **Then** it imports no framework, no ORM and no I/O, calls no `new Date()`, and its unit tests run with no database and no HTTP.
