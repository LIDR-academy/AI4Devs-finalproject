# [C1] T-C1-93 · Conversion domain rule: reference and history preserved, state-equivalence refusal

## Context

`US-C1-27` requires a converted record to **preserve its original reference number** (`NFR-DAT-01`), keep its **full comment and activity history readable**, with **no history entry deleted or rewritten** (`NFR-AUD-02`); and requires conversion from a state with **no meaningful equivalent in the target type** to be refused with a typed error naming the reason, rather than landing the record in an undefined state.

**Boundary.** The story is unambiguous: **the Service Request side belongs to `C2`; this story delivers only the Incident side of the exchange, and the two must ship together.** No `C2` ticket is written in this epic, and this epic cannot be accepted as delivering `FR-INC-14` alone.

## Scope

- Conversion rules on the `Incident` aggregate: which Incident states have a meaningful Service Request equivalent, expressed as data rather than a hardcoded switch, and the typed refusal for those that do not.
- Reference preservation: the `TicketReference` is carried through unchanged, and the never-reuse guarantee of `T-C1-04` continues to hold across a conversion.
- History preservation: entries, assignments, resolutions and events remain readable and unmodified after conversion.
- Out of scope: the Service Request aggregate, its states and its creation — all `C2`; the use case and event (`T-C1-94`); the UI (`T-C1-95`).

## Acceptance criteria

**Given** an Incident in a state with a defined equivalent **When** conversion is evaluated **Then** it is permitted and the target state is named explicitly by the mapping.

**Given** an Incident in a state with no defined equivalent **When** conversion is attempted **Then** it is refused with a typed error naming the state and the reason, and the record is unchanged.

**Given** a converted record **When** its reference is read **Then** it is the original reference, and no new reference was allocated.

**Given** a converted record **When** its history is read **Then** every prior entry, assignment and resolution is present and unmodified.
