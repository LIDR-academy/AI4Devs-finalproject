# [C1] T-C1-34 · Return to the derived value and the documented precedence rule

## Context

`US-C1-10` requires that the system does **not** silently re-derive over an override: the override stands until an agent **explicitly returns** the Incident to the derived value, and that action is itself audited.

**Blocked by finding F30.** This is the ticket that encodes the disputed rule. `FR-INC-04` and `FR-INC-05` can contradict each other and the PRD does not say which wins; the stories assume override-stands-until-explicitly-returned. Build it to that assumption, keep the rule in the single predicate of `T-C1-32`, and record it as an assumption awaiting Product Owner confirmation — flipping the decision must be a one-line change in that predicate, not a rewrite across use cases.

## Scope

- `ReturnPriorityToDerivedUseCase` in `libs/incident/application`, permission-gated like the override.
- `PriorityOverrideCleared` event carrying actor, the overridden value being abandoned and the derived value taking effect.
- A written statement of the precedence rule in the ticket's implementation notes and in the domain predicate's documentation, so the assumption is discoverable in the code rather than only in the backlog.
- Out of scope: the domain rule itself (`T-C1-32`); the flag interaction test (`T-C1-47`); the UI (`T-C1-35`).

## Acceptance criteria

**Given** an Incident with an overridden Priority **When** an agent returns it to the derived value **Then** the effective Priority becomes the derived value, the overridden flag clears, and exactly one `PriorityOverrideCleared` event is published after commit.

**Given** an Incident with an overridden Priority **When** Impact or Urgency changes without an explicit return **Then** the effective Priority remains the overridden value, and the newly derived value is recorded alongside it.

**Given** an actor without the prioritization permission **When** they attempt the return **Then** it is denied with `403` and nothing changes.

**Given** the precedence assumption **When** the code is read **Then** the single predicate documents it explicitly as an assumption pending confirmation, naming finding **F30**.
