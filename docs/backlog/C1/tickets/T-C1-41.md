# [C1] T-C1-41 · Deterministic behavior at the Impact-scale ceiling

## Context

`US-C1-11` requires that when an Incident's assessed Impact is **already at the top of the scale** and the flag is set, the behavior is deterministic and **never a silent no-op that leaves the agent believing the escalation took effect**.

**Blocked by finding F24.** `FR-INC-05` says the flag raises assessed Impact "by a configurable amount" and says nothing about the ceiling. Two defensible behaviors exist — **clamp at the ceiling** and report that the flag was recorded without further uplift, or **refuse the flag** with a typed error stating the Incident is already at maximum Impact. This backlog does **not** choose: the choice changes whether the flag is always meaningful or sometimes inert, and it is the **Product Owner's** decision.

What is not blocked: the *shape* of the outcome. Build the ceiling path so that it returns an explicit, typed, testable result either way, with the chosen branch selected in one place; the silent no-op is forbidden regardless of which branch is chosen.

## Scope

- An explicit ceiling outcome type in `libs/incident/domain` — the uplift result is never "the same Impact with no explanation".
- A single decision point where the chosen ceiling behavior is applied, documented as awaiting **F24**.
- Unit tests for both candidate behaviors, with the one not chosen marked pending rather than deleted, so the decision is a switch and not a rewrite.
- Out of scope: choosing the behavior — that is a Product Owner decision, recorded in `docs/backlog/C1/test-plan.md` as an open decision.

## Acceptance criteria

**Given** an Incident already at the top of the Impact scale **When** the flag is set **Then** the result is an explicit typed outcome — never an unchanged Incident returned as success with no statement of what happened.

**Given** that outcome **When** it reaches the agent **Then** it states either that the flag was recorded without further uplift, or that the flag was refused because Impact is already at maximum, according to the decided behavior.

**Given** the ceiling path **When** the domain library is searched **Then** exactly one decision point exists and it names finding **F24** in its documentation.

**Given** the decision is still open **When** the epic is reviewed **Then** this ticket is reported as blocked, and `FR-INC-05` is not claimed complete on the strength of the non-ceiling path alone.
