## Scope

- Generate exactly six libraries with the tags of `ARCHITECTURE.md` §5.5:
  - `libs/incident/domain` — `platform:backend,scope:incident,type:domain`
  - `libs/incident/application` — `platform:backend,scope:incident,type:application`
  - `libs/incident/infrastructure` — `platform:backend,scope:incident,type:infrastructure`
  - `libs/incident/feature` — `platform:frontend,scope:incident,type:feature`
  - `libs/incident/ui` — `platform:frontend,scope:incident,type:ui`
  - `libs/incident/data-access` — `platform:frontend,scope:incident,type:data-access`
- Barrel `index.ts` per library; Jest configured per library; path aliases registered in `tsconfig.base.json`.
- Out of scope: any aggregate, port, use case, entity, component or migration. Also out of scope: the `apps/api` module wiring and the `incident` schema namespace (`T-C1-02`).
