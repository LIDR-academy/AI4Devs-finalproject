# [C1] T-C1-45 · No automated write path exists — the system-actor refusal proof

## Context

`US-C1-12` states the property this ticket makes falsifiable: given **any** automated source — a schedule or calendar, an SCMS fixture feed, a time-based workflow rule, an SLA threshold event, or an imported record — it **cannot** set, change or clear the flag; **no automated code path exists that writes it**. The story then requires the decisive test: *“a test asserts that invoking it with a system actor (the rule actor of `FR-AUD-02`) is refused, so ‘never automatically’ is a falsifiable property and not a comment.”*

This is the most important ticket in the epic. The priority escalation of this product is a deliberate, accountable human judgement, and ADR-006 already records that Sport ITSM has **no competition calendar, no live windows and no freeze windows** — there is no automated source to connect even if someone wanted one.

Related boundary: `T-C1-78` receives SLA threshold events and performs an **escalation**. That path must never touch the flag, and the assertion below covers it.

## Scope

- An explicit actor-kind check in the flag write path refusing the **system/rule actor** of `FR-AUD-02` with a typed domain error, distinct from an ordinary permission denial so the two are distinguishable in reporting.
- Unit test invoking the flag write with a system actor and asserting refusal — the falsifiability the story demands.
- A static assertion over `libs/incident/{domain,application,infrastructure}` and the `apps/api` incident wiring that the flag mutator is referenced by exactly one caller: the agent use case of `T-C1-43`.
- A named test asserting that the SLA-threshold handler of `T-C1-78` and every scheduled or event-driven handler in the `incident` context reach no flag mutator.
- Out of scope: the field rejection at the transport boundary (`T-C1-44`); the permission denial for a human actor without the permission (`T-C1-43`).

## Acceptance criteria

**Given** the flag write path **When** it is invoked with the system/rule actor of `FR-AUD-02` **Then** it is refused with a typed error, the flag is unchanged, and no event is published.

**Given** a scheduled job, an imported record, an SLA threshold event and a workflow rule **When** each is processed **Then** none reaches a flag mutator, asserted by a caller enumeration rather than by inspection.

**Given** the flag mutator **When** its callers are enumerated across the `incident` libraries and the `apps/api` wiring **Then** there is exactly one, and adding a second fails the test.

**Given** a system actor and a human actor lacking the permission **When** each attempts the write **Then** the two refusals are distinguishable, so never-automatic and not-permitted are separately reportable.
