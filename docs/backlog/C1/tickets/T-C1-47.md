# [C1] T-C1-47 · Flag and Priority-override interaction rule, with its explicit test

## Context

`US-C1-13` requires that when an Incident whose Priority was overridden per `US-C1-10` has the flag set or cleared, the interaction between override and re-derivation **follows the single documented rule of `US-C1-10`** and is exercised by an **explicit test**, so the two mechanisms cannot disagree.

**Blocked by finding F30.** `FR-INC-04` and `FR-INC-05` can contradict each other and the PRD does not say which wins. This backlog assumes the override stands until an agent explicitly returns the Incident to the derived value (`T-C1-32`, `T-C1-34`). This ticket is the place that assumption becomes visible: it consumes the single precedence predicate rather than restating the rule, so a Product Owner decision flips both mechanisms at once.

The story records why it matters: two independently reasonable implementations exist and **they produce different P1 counts**.

## Scope

- Composition of the flag re-derivation of `T-C1-40` and `T-C1-46` with the precedence predicate of `T-C1-32` — no second rule, no branch local to the flag handler.
- Explicit unit tests over the four combinations: override present or absent, crossed with flag set or cleared.
- The resulting effective Priority, the derived Priority and the overridden Priority all remain separately readable after each combination.
- Out of scope: choosing the rule — a Product Owner decision; the override use cases (`T-C1-33`, `T-C1-34`).

## Acceptance criteria

**Given** an Incident with an overridden Priority **When** the flag is set **Then** the effective Priority follows the single precedence predicate, the newly derived value is recorded alongside, and both are readable.

**Given** the same Incident **When** the flag is cleared **Then** the outcome follows the same predicate, with no branch specific to the flag handler.

**Given** the four combinations of override present/absent and flag set/cleared **When** the tests run **Then** each has an explicit named assertion, and no combination is left unasserted.

**Given** the flag handler **When** the domain library is searched **Then** it contains no precedence logic of its own; it calls the predicate defined once by `T-C1-32`.
