# [C1] T-C1-81 · `IncidentLink` — typed reference, direction and cycle prevention

## Context

`US-C1-20` requires a duplicate link to have an **explicit direction** — which is the duplicate and which is the original — and requires that an Incident **cannot be marked a duplicate of itself, nor can a duplicate chain form a cycle**. `US-C1-21` requires the link to be a **typed reference — target kind plus target identifier** — so adding Problem, Change, Release and Configuration Item targets needs no change to the Incident model when `C3`, `C4`, `C5` and `C6` arrive.

One model serves both stories: the Incident-to-Incident links of `US-C1-20` are the same typed reference with an Incident target kind.

## Scope

- `IncidentLink` value object in `libs/incident/domain`: link kind — duplicate, related, parent Major Incident, Problem, Change, Release, Configuration Item — plus target kind and target identifier.
- Direction explicit for duplicate links; self-link refused with a typed domain error.
- Cycle detection over duplicate chains, refusing a link that would close a cycle.
- Target kinds whose owning context is not deployed declared but not enabled, per `T-C1-85`.
- Out of scope: persistence (`T-C1-82`); the use cases (`T-C1-83`); the Major Incident parent semantics (`T-C1-84`); every target-side aggregate, which belongs to `C3`, `C4`, `C5`, `C6` and `C13`.

## Acceptance criteria

**Given** an Incident **When** it is linked as a duplicate of itself **Then** it is refused with a typed domain error.

**Given** a duplicate chain A→B→C **When** C is linked as a duplicate of A **Then** it is refused because it would close a cycle.

**Given** a duplicate link **When** it is read **Then** which Incident is the duplicate and which is the original is explicit, not inferred from creation order.

**Given** a link to a Problem, a Change, a Release or a Configuration Item **When** the model is inspected **Then** the link is a target-kind plus identifier pair, and enabling a new kind requires no change to the `Incident` aggregate.
