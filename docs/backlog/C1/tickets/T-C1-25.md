# [C1] T-C1-25 · Categorization gate on exit from `New`

## Context

`US-C1-07` requires an uncategorized Incident to be stopped from leaving `New`, with a typed domain error naming the missing category and no state change. It explicitly requires the gate to live in the `incident` **domain or application layer**, unit-tested with no HTTP and no database, so it holds on **every inbound path** and not only in the UI.

It equally requires that creation by a requester with no category **succeeds** — categorization is a triage responsibility, and the gate applies at exit from `New`, not at intake.

## Scope

- Transition guard in `libs/incident/domain` refusing any transition out of `New` when no Item-level category is set.
- Typed domain error naming the missing category, mapped to a contract error code by the existing exception filter.
- Unit tests covering: no category, a category set only to Category or Subcategory level, and a full Item-level category.
- Out of scope: the state model and the other transition rules (`T-C1-49`, `T-C1-51`) — this guard composes with them; the picker (`T-C1-24`).

## Acceptance criteria

**Given** an Incident in `New` with no category **When** any transition out of `New` is attempted **Then** it is refused with a typed domain error naming the missing category and the state is unchanged.

**Given** an Incident in `New` whose category is set only to the Category or Subcategory level **When** a transition out of `New` is attempted **Then** it is refused for the same reason — the gate requires the Item level.

**Given** an Incident in `New` with an Item-level category **When** a transition out of `New` is attempted **Then** the guard permits it, subject to the other transition rules of `US-C1-15`.

**Given** an Incident created by a requester with no category **When** it is submitted **Then** creation succeeds and the Incident rests in `New`.

**Given** the guard **When** it is unit-tested **Then** the tests run with no HTTP and no database, proving the rule holds independently of any inbound adapter.
