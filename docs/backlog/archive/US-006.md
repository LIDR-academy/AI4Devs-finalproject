## US refinada

**Historia de usuario:**
Como corredor, quiero seleccionar la talla y el color del producto que quiero comprar, para asegurarme de que la variante añadida al carrito es la correcta.

**Contexto técnico:**

- La ficha de producto (`/product/[id]`) es actualmente un **Server Component** (`page.tsx`) que renderiza imagen, nombre, atributos y un botón «Añadir al carrito» estático.
- El backend ya devuelve `sizes[]`, `colors[]` y `stock` en `GET /api/products/:id` — **no se requiere ningún cambio backend en esta US**.
- La interactividad (selección de variante, stepper de cantidad, validación) exige estado React, por lo que se extrae a un nuevo **Client Component** (`ProductVariantSelector`) que se monta dentro del Server Component.
- El botón «Añadir al carrito» existe en la página actual pero es un stub estático. US-006 añade la UI de selección y la validación. La llamada real a la API del carrito se implementa en US-007.
- El tamaño y el color son opcionales en el modelo de datos (`CartItem.size?: string`, `CartItem.color?: string`), pero la implementación establece que **tanto la talla como el color son obligatorios cuando el producto los tiene** (i.e., `sizes.length > 0` y `colors.length > 0` respectivamente).
- Los valores de `colors[]` en BD están en inglés (`'black'`, `'white'`, etc.); `ProductVariantSelector` los mapea a español mediante `COLOR_LABELS` de `product-utils.ts` antes de renderizarlos. El `selectedColor` en estado guarda la etiqueta española.

**Contrato del componente `ProductVariantSelector`:**

```tsx
interface ProductVariantSelectorProps {
  sizes: string[];     // de Product.sizes
  colors: string[];    // de Product.colors
  stock: number;       // de Product.stock
  // onAddToCart se introduce en US-007; en US-006 el botón muestra validación sin efecto real
}

// Estado interno
state: {
  selectedSize: string | null;
  selectedColor: string | null;
  quantity: number;        // 1..stock
  sizeError: boolean;      // true cuando se pulsa añadir sin talla en producto con tallas
  colorError: boolean;     // true cuando se pulsa añadir sin color en producto con colores
}
```

**Comportamiento explicitado:**

| Situación | Comportamiento |
|---|---|
| `sizes.length === 0` | El `SizeSelector` no se renderiza; el corredor puede pulsar añadir sin seleccionar talla |
| `sizes.length > 0` y ninguna talla seleccionada al pulsar añadir | Se muestra el aviso «Por favor, selecciona una talla» (inline, sin toast); no se añade al carrito |
| `colors.length > 0` y ningún color seleccionado al pulsar añadir | Se muestra el aviso «Por favor, selecciona un color» (inline, sin toast); no se añade al carrito |
| Faltan talla y color a la vez | La validación de talla tiene prioridad; se muestra primero «Por favor, selecciona una talla» |
| `stock === 0` | El botón «Añadir al carrito» aparece deshabilitado con texto «Agotado» |
| Quantity en límite inferior (1) | El botón «−» queda deshabilitado |
| Quantity en límite superior (stock) | El botón «+» queda deshabilitado |

**Criterios de aceptación cubiertos:**

1. El corredor selecciona talla y color mediante botones; la variante seleccionada queda marcada visualmente.
2. Si el producto no tiene tallas disponibles, el selector de talla no se muestra.
3. El stepper de cantidad permite valores entre 1 y el stock disponible.
4. Al pulsar «Añadir al carrito» sin talla en un producto que la requiere, se muestra «Por favor, selecciona una talla».
5. La cantidad no puede superar el stock ni ser inferior a 1; el stepper bloquea los límites.
6. Al pulsar «Añadir al carrito» sin color en un producto que lo requiere, se muestra «Por favor, selecciona un color». *(comportamiento añadido durante la implementación)*
