# [C10] T-C10-61 · Web step-up re-authentication prompt

## Context

The client half of `T-C10-60`: `US-C10-15` requires the administrator to re-enter credentials and then have the original operation retried and succeed.

**Blocked by finding F16** — which operations trigger the prompt is an unconfirmed assumption of this backlog, pending Product Owner confirmation. The prompt itself is buildable; what triggers it is not fixed.

Phase: `unphased` (finding **F9**).

## Scope

- Interceptor handling of the distinct re-authentication-required error code from `T-C10-60`: open the step-up prompt rather than routing to sign-in, which is what a `401` does.
- Step-up overlay built from `T-C10-14` and the form primitives of `T-C10-13`: credential entry, cancel, and a clear explanation of why it is being asked.
- On success, the original request is retried transparently and its result is delivered to the original caller; on cancel, the operation is abandoned and the screen says so.
- Invalid credentials show an error in the prompt without closing it and without signing the user out.
- Jest tests for retry, cancel and invalid credentials.
- Out of scope: the server-side enforcement; the membership of the privileged set.

## Acceptance criteria

**Given** a privileged action refused for re-authentication **When** the response reaches the client **Then** the step-up prompt opens and the user is not signed out.

**Given** valid credentials in the prompt **When** they are submitted **Then** the original request is retried automatically and its result reaches the original caller.

**Given** invalid credentials in the prompt **When** they are submitted **Then** an error is shown inside the prompt, the prompt stays open, and the session is not terminated.

**Given** the prompt is cancelled **When** it closes **Then** the operation is abandoned, the screen states that nothing was changed, and focus returns to the invoking control.

**Given** a genuine `401` **When** it reaches the interceptor **Then** the client routes to sign-in and does **not** open the step-up prompt.
