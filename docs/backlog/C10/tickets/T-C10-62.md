# [C10] T-C10-62 · `AuthorizationDenial` record produced by the deciding predicate

## Context

`US-C10-16` requires a denial record carrying the actor identity, the attempted operation, the target record reference where one exists, the reason for denial and the `ClockPort` timestamp — produced by the **same use-case-level predicate that made the decision**, so it can never disagree with the outcome the caller received.

**Blocked by finding F16.** The requirement is scoped to privileged operations, and the set of privileged operations is not defined anywhere in the PRD or the architecture. `US-C10-16` reuses the assumed set proposed by `US-C10-15`. **The Product Owner must confirm that set.** The record shape and the production point are unblocked and are built here; the scoping condition inherits the provisional registry of `T-C10-59` and cannot be finalized until F16 is resolved.

Phase: `unphased`. `FR-IAM-07` is assigned to no phase in PRD §14 — finding **F9**.

## Scope

- `AuthorizationDenial` value object in `libs/identity-access/domain`: actor identity, attempted operation, optional target record reference, denial reason, timestamp from `ClockPort`.
- Produced at the point of decision in the application layer, from the denial reason the predicate of `T-C10-38` already returns.
- Scoped to operations in the privileged registry of `T-C10-59`; an ordinary visibility denial produces nothing, so the volume does not drown the signal.
- Emitted through a `AuthorizationDenialSinkPort` declared in the domain — the sink implementation is `T-C10-63` and is blocked by finding **F17**.
- Jest unit tests: privileged denial produces a record, non-privileged denial produces none, record contains no credential material.
- Out of scope: where the record is stored (`T-C10-63`, blocked by **F17**); the membership of the privileged set (**F16**).

## Acceptance criteria

**Given** a privileged operation **When** the authorization predicate denies it **Then** exactly one `AuthorizationDenial` is produced, carrying the actor identity, the attempted operation, the target record reference where one exists, the denial reason and the `ClockPort` timestamp.

**Given** a denial on a non-privileged operation **When** it occurs **Then** no denial record is produced.

**Given** an unauthenticated request rejected by the global guard **When** it is rejected **Then** it is an authentication failure and produces no denial record.

**Given** a denial record **When** it is inspected **Then** it contains no credential, no token and no password.

**Given** the record and the response the caller received **When** they are compared **Then** the reason in the record is the reason the predicate returned, because both come from the same decision.
