# [C10] T-C10-14 · `libs/shared/ui` — overlay primitive, focus trap/restore and `aria-live` announcer

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, the `libs/shared/ui` row, which names *a11y directives* explicitly, and ADR-010, which names the focus-trap/restore directive and the `aria-live` announcer as contents of this library; and finding **F14** of `user-stories.md`.

`US-C10-11` requires an `aria-live` confirmation on role assignment, `US-C10-14` requires a session-expiry warning with a *stay signed in* action, and `US-C10-15` requires a step-up credential prompt. All three are overlays with focus management.

## Scope

- Hand-built dialog/overlay component: `role="dialog"`, `aria-modal`, labelled by its own heading, `Escape` to dismiss where dismissal is allowed, backdrop that does not steal focus.
- Focus-trap and focus-restore directive: focus moves into the overlay on open, cycles within it, and returns to the invoking element on close.
- `aria-live` announcer service exposing polite and assertive channels, rendering into a single visually hidden region owned by the library.
- Jest tests: focus enters on open, cycles at both ends, restores on close; announcements land in the live region with the requested politeness.
- Out of scope: any specific dialog content. The inactivity warning, the step-up prompt and every confirmation are composed by the consuming feature libraries.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** an open overlay **When** `Tab` is pressed on the last focusable element **Then** focus moves to the first focusable element inside the overlay and never to the page behind it.

**Given** an overlay opened from a trigger button **When** it closes **Then** focus returns to that trigger.

**Given** the announcer **When** a polite message is announced **Then** exactly one `aria-live="polite"` region exists in the document and it receives the message text.

**Given** the library **When** `pnpm nx test shared-ui` and `pnpm nx lint shared-ui` run **Then** both pass and the library still depends on nothing beyond `scope:shared` `type:util`.
