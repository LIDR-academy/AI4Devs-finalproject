# [C10] T-C10-55 · Post-commit event dispatch with failure isolation

## Context

`US-C10-13` requires the event to be published **when the transaction commits**, requires a failing subscriber to leave the role change committed with the dispatch failure logged, and requires that a failed or denied role change emits nothing at all. `ARCHITECTURE.md` §9 and ADR-008 place the single in-process dispatcher in `apps/api` behind `EventPublisherPort`.

**Dependency:** `C18` supplies the subscriber that turns these events into audit entries (finding **F5**). This ticket delivers the publication side and is complete without that subscriber; the acceptance scenarios use a test subscriber.

## Scope

- In-process dispatcher in `apps/api` bound to `EventPublisherPort` from `T-C10-09`, invoked **after** commit, never inside the transaction.
- The assignment and revocation use cases collect events on the aggregate and hand them to the publisher only on a successful commit.
- Subscriber failures are caught, logged with the correlation identifier, and never propagated into the caller or the transaction.
- Jest unit tests plus an API-E2E scenario with a deliberately failing test subscriber.
- Out of scope: the audit subscriber, persistence of events, retry policy beyond logging — `C18` owns the durable side.

## Acceptance criteria

**Given** a successful role assignment **When** the transaction commits **Then** `RoleAssigned` is published exactly once, after the commit.

**Given** a successful role revocation **When** the transaction commits **Then** `RoleRevoked` is published exactly once.

**Given** a subscriber that throws **When** the event is dispatched post-commit **Then** the role change stays committed, the caller receives success, and the dispatch failure is logged with the correlation identifier.

**Given** a role change that is denied by authorization or fails validation **When** the use case returns **Then** no `RoleAssigned` and no `RoleRevoked` event is emitted.

**Given** an idempotent repeat assignment **When** it completes **Then** no event is emitted, because nothing changed.
