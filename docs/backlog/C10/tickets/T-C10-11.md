# [C10] T-C10-11 · `libs/shared/contracts` — baseline DTO, enum and error-code surface

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, row *`libs/shared/contracts`, `libs/shared/util`*, noted there as *The only FE↔BE coupling (ADR-007)*; and finding **F14** of `user-stories.md`.

Per ADR-007 this library holds **types only** — no logic, no framework, and specifically **no `class-validator` decorators**: backend DTO classes carrying decorators live on the API side and structurally implement these types. `US-C10-11` requires the role-assignment body to be validated by a `class-validator` DTO defined against a contract, so the split must exist before that ticket.

## Scope

- `pnpm nx g @nx/js:lib shared-contracts --directory=libs/shared/contracts --tags=platform:shared,scope:shared,type:contracts`.
- The cross-cutting HTTP contract shapes of `ARCHITECTURE.md` §3.2: the error envelope, the machine-readable error-code enum seeded with `UNAUTHENTICATED`, `FORBIDDEN`, `VALIDATION_FAILED` and `NOT_FOUND`, plus the pagination and correlation-identifier shapes.
- Document the convention in the barrel: contract types are declared here; decorated DTO classes implementing them live in `apps/api`.
- Out of scope: every identity-specific contract — sign-in (`T-C10-27`), sign-out (`T-C10-33`), role assignment (`T-C10-48`) and role revocation (`T-C10-52`) each add their own.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** the library source **When** it is grepped for `class-validator`, `@nestjs`, `@angular` and `typeorm` **Then** there is no match.

**Given** the library **When** it is inspected **Then** it contains no runtime logic beyond type declarations and `const` enums.

**Given** a probe import from `libs/shared/contracts` into any `type:domain` library **When** lint runs **Then** it fails, because `type:domain` may not depend on `type:contracts` (`ARCHITECTURE.md` §5.3); the probe is reverted before the ticket is closed.

**Given** the project **When** its tags are inspected **Then** they are exactly `platform:shared`, `scope:shared`, `type:contracts`, and `pnpm nx lint shared-contracts` passes.
