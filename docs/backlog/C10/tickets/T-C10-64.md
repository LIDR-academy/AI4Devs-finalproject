# [C10] T-C10-64 · SCMS SSO adapter behind `IdentityProviderPort`

## Context

`US-C10-10` requires the SSO adapter to translate the external SCMS identity and its profile attributes into the local `User` model, with **no SCMS-specific field name, claim shape or type** crossing into `type:domain` or `type:application`. The port and the binding mechanism already exist (`T-C10-20`, `T-C10-23`), so this is the adapter swap those tickets were designed for.

Phase: `unphased`. `FR-IAM-04` is assigned to no phase in PRD §14 — finding **F9**. It is also a `S` (Should) requirement and depends on the SCMS identity provider being available, which the PRD records as assumption A2 and dependency D1.

## Scope

- `ScmsSsoIdentityProvider` in `libs/identity-access/infrastructure` implementing `IdentityProviderPort`.
- An explicit anti-corruption mapper translating SCMS claims into the domain identity and a normalized profile-attribute map; the SCMS claim vocabulary lives only in this file.
- Configuration for the provider endpoint, client credentials and the claim mapping, all through `ConfigService` and validated at boot.
- Selectable through the binding of `T-C10-23` by configuration alone, with no change to any use case.
- Jest unit tests against a stubbed SCMS client, plus a contract test over a recorded provider response.
- Out of scope: provisioning (`T-C10-65`), profile refresh (`T-C10-66`), outage handling (`T-C10-67`).

## Acceptance criteria

**Given** the SSO adapter bound as the `IdentityProviderPort` implementation **When** a user authenticates through the SCMS identity provider **Then** the adapter returns a domain identity and a normalized profile map.

**Given** `type:domain` and `type:application` **When** they are grepped for any SCMS-specific claim name or type **Then** there is no match.

**Given** the configured provider switched from `local` to the SSO value **When** the application boots **Then** the SSO adapter is bound and no use case changed.

**Given** a claim missing from the provider response **When** the mapper runs **Then** it fails with a typed mapping error naming the claim, rather than producing a partially populated identity.
