# [C10] T-C10-19 · `User` aggregate and identity value objects

## Context

`US-C10-01` requires a registered, **active** user with a hashed credential, and requires that a credential is never held in reversible form. The aggregate that carries those invariants is the first domain object of the `identity-access` context and every later ticket in this epic reads from it.

Greenfield: nothing exists yet. Built on the `Identity` primitive from `T-C10-08`.

## Scope

- `User` aggregate root in `libs/identity-access/domain`: identity, display name, account status (active / inactive), credential reference, assigned role identifiers.
- Value objects: `UserId` (over `Identity`), `EmailAddress` or `UserIdentifier` with construction-time validation, `AccountStatus`.
- `PasswordHash` value object that holds a hash only, exposes no plaintext accessor, and whose `toString`/`toJSON` never reveal the hash.
- Invariants: an inactive user cannot be authenticated; a user always has zero or more role identifiers and never a duplicate.
- Jest unit tests for every invariant, with no framework, no database and no HTTP.
- Out of scope: persistence (`T-C10-21`), the authentication use case (`T-C10-25`), the role catalog (`T-C10-35`).

## Acceptance criteria

**Given** the `identity-access/domain` library **When** its imports are inspected **Then** it imports only `libs/shared/domain` and `libs/shared/util`, with no NestJS, TypeORM, Express or Passport import.

**Given** a `PasswordHash` **When** it is serialized, logged or interpolated into a string **Then** the hash value does not appear in the output.

**Given** a `User` **When** it is constructed with an unknown account status or a malformed identifier **Then** construction raises a typed domain error.

**Given** a `User` marked inactive **When** the aggregate is asked whether it may be authenticated **Then** it answers no, and that decision is expressed on the aggregate rather than in a caller.

**Given** the same role identifier assigned twice **When** the aggregate is inspected **Then** it holds one occurrence, not two.
