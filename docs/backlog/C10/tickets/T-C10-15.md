# [C10] T-C10-15 · `libs/shared/ui` — table, badge and state primitives

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, the `libs/shared/ui` row naming the design-system primitives (ADR-010); and finding **F14** of `user-stories.md`.

The role-administration screen (`T-C10-50`) lists users and their assigned roles, and `US-C10-12` requires an explicit *no entitlements* state rather than an empty screen or a silent error. Both need these primitives.

## Scope

- Hand-built data table: native `table` semantics, `scope` on header cells, caption support, keyboard-reachable row actions, horizontal overflow contained in the component.
- Badge/chip primitive for role labels, with a text label that is never conveyed by color alone.
- Empty-state, error-state and loading-state components — the three states every data surface in this product must render explicitly (`CLAUDE.md` §3 forbids undefined loading and error states).
- Jest component tests for table semantics and for each of the three states.
- Out of scope: any role-specific or domain-specific wording; the design tokens themselves (`T-C10-12`).

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** the table primitive **When** its rendered DOM is inspected **Then** it uses native `table`, `thead`, `tbody` and `th` with `scope`, not `div` elements with table roles.

**Given** the badge primitive **When** it renders any state **Then** the state is carried by text content, not by color alone.

**Given** a consuming surface **When** it has no data, an error, or a request in flight **Then** exactly one of the three state components is rendered and none of them is an empty template.

**Given** the library **When** `pnpm nx test shared-ui` and `pnpm nx lint shared-ui` run **Then** both pass.
