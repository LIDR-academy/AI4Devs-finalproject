# [C10] T-C10-12 · `libs/shared/ui` — design tokens and theming layer

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, row *`libs/shared/ui` — the in-house design system (primitives, design tokens, a11y directives)*, priced in `C10` citing ADR-010, with the note that `C10` ships the first authenticated frontend surface and therefore the design system must exist there; and finding **F14** of `user-stories.md`.

There is no third-party component library in this product (`CLAUDE.md` §3), so every visual primitive is hand-built. Tokens come first: `US-C10-11` requires the role-administration screen to render through the design system, and `T-C10-13` to `T-C10-15` all consume this layer.

## Scope

- `pnpm nx g @nx/angular:lib shared-ui --directory=libs/shared/ui --tags=platform:frontend,scope:shared,type:ui` (`ARCHITECTURE.md` §5.5 — note the platform tag is `frontend`, not `shared`, per ADR-010).
- SCSS design-token layer as CSS custom properties: color roles, spacing scale, typography scale, radii, elevation, focus-ring, motion durations.
- Light and dark token sets plus a high-contrast-safe focus ring meeting WCAG 2.1 AA contrast.
- Token entry point importable from `apps/web` global styles.
- Out of scope: any component (`T-C10-13` to `T-C10-15`); any domain vocabulary — domain-aware components belong in a context `type:ui` library.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** the library **When** its dependencies are inspected **Then** it depends on nothing but `scope:shared` `type:util`, and `pnpm nx lint shared-ui` passes.

**Given** any stylesheet in the library **When** it is grepped for a raw hex color, a raw pixel spacing value or `::ng-deep` **Then** there is no match outside the token definition file itself.

**Given** the token layer **When** the two color roles used for body text and background are measured **Then** the contrast ratio is at least 4.5:1 in both the light and the dark set.

**Given** the project **When** its tags are inspected **Then** they are exactly `platform:frontend`, `scope:shared`, `type:ui`.
