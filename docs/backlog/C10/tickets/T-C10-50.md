# [C10] T-C10-50 · Role administration screen

## Context

`US-C10-11` requires the System Administrator to assign roles from the Admin Console, with the assignment visible on the user profile immediately, rendered through the **in-house design system**, keyboard operable, with an `aria-live` confirmation and **no third-party component library**.

## Scope

- Routed standalone `OnPush` component in `libs/identity-access/feature`, composed from `libs/shared/ui` (table, badge, form primitives, state components) and the store of `T-C10-49`.
- User list with the current roles per user, a role picker, and an assign action.
- Success announced through the `aria-live` announcer of `T-C10-14`; failure rendered as an explicit error state.
- Loading, empty and error states all rendered explicitly; the route is guarded so a non-administrator never reaches it, with the server predicate remaining the real authority.
- Transloco keys for every string; Angular control flow (`@if`, `@for` with `track`).
- Out of scope: the revoke action and the no-entitlements state (`T-C10-53`), the step-up prompt (`T-C10-61`, blocked by finding **F16**).

## Acceptance criteria

**Given** an administrator on the role-administration screen **When** they assign a role to a user **Then** the assignment is persisted and the user row shows the new role without a manual reload.

**Given** that successful assignment **When** it completes **Then** a confirmation is announced through the `aria-live` region.

**Given** the screen **When** it is operated by keyboard only **Then** every control including the row actions is reachable, has a visible focus indicator and activates without a pointer.

**Given** the component source **When** it is inspected **Then** it uses `@if` and `@for` with `track`, carries `OnPush`, imports no third-party component library and contains no hardcoded user-facing string.

**Given** a non-administrator who reaches the route by URL **When** the screen attempts an assignment **Then** the API denies it with `403` and the screen renders the denial rather than a silent failure.
