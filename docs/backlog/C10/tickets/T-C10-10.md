# [C10] T-C10-10 · `libs/shared/domain` — `StateModel` and transition rules

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, the `libs/shared/domain` row, whose note reads *The `StateModel` primitive is consumed by `C12`* — it is priced in `C10` and therefore built here, then instantiated by every later lifecycle. `ARCHITECTURE.md` §4.1 rejects a central workflow-engine context and realizes C12 as this primitive plus per-context configuration. Also finding **F14** of `user-stories.md`.

No `C10` story consumes `StateModel`. It is carried here only because the epic map prices it here; building it later would force the first lifecycle of `C12` to be rewritten.

## Scope

- Generic `StateModel` over a state type and a transition type: declared states, allowed transitions, one guard predicate per transition, terminal-state marking.
- Typed `IllegalTransitionError` naming source state, target state and the rule that rejected it.
- Jest tests: legal transition accepted, undeclared transition rejected, guard denial, terminal state accepts no outbound transition.
- Out of scope: any concrete lifecycle. `C10` declares no state machine of its own; the `Session` status in `T-C10-24` is a two-value flag, not a `StateModel` instance.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** a `StateModel` configured with states and transitions **When** an undeclared transition is attempted **Then** it raises `IllegalTransitionError` naming both states.

**Given** a transition whose guard predicate denies **When** the transition is attempted **Then** it is rejected and the model state is unchanged.

**Given** the primitive **When** its source is inspected **Then** it contains no context vocabulary — no ticket, incident, change or role term — and no framework import.

**Given** the library **When** `pnpm nx test shared-domain` runs **Then** the transition suite passes.
