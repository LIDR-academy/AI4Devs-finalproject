# [C10] T-C10-22 · Local-credential adapter with bcrypt verification

## Context

`US-C10-09` requires the local-credential adapter to perform the bcrypt comparison and return a domain identity, so that the domain never sees a hash, a request object or a driver type. This is the adapter that satisfies `FR-IAM-01` today and that `FR-IAM-04` will later swap for SSO.

Phase 0 for the same reason as `T-C10-20`: the local adapter is what makes phase-0 authentication work; the unphased half of `FR-IAM-04` is the SSO adapter in block H.

## Scope

- `LocalCredentialIdentityProvider` in `libs/identity-access/infrastructure` implementing `IdentityProviderPort`.
- bcrypt hashing and comparison with a configurable cost factor read through `ConfigService`; comparison is constant-time by construction of the library call.
- Maps repository misses and inactive accounts onto the typed failures of `T-C10-20`; never returns a hash upward.
- A credential-hashing helper used by seeding and by future password changes, so bcrypt is called from exactly one place.
- Jest unit tests against a stubbed `UserRepositoryPort`, plus one integration test proving a hash produced by the helper verifies through the adapter.
- Out of scope: the sign-in use case (`T-C10-25`), token issuance (`T-C10-26`), the SSO adapter (`T-C10-64`).

## Acceptance criteria

**Given** a stored bcrypt hash and the matching plaintext credential **When** the adapter verifies it **Then** it returns a resolved domain identity carrying no hash field.

**Given** a non-matching credential **When** the adapter verifies it **Then** it returns `InvalidCredential` and performs the comparison anyway for an unknown identifier, so response timing does not disclose existence.

**Given** an inactive account with a correct credential **When** the adapter verifies it **Then** it returns `AccountInactive` and no identity.

**Given** the adapter source **When** it is grepped **Then** bcrypt is imported in this library only, and no plaintext credential is written to a log line at any level.
