# [C10] T-C10-05 · Scaffold `apps/web` — Angular 20 standalone shell

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, row *`apps/api`, `apps/api-e2e`, `apps/web`, `apps/web-e2e` (4 applications)*, priced in `C10`; and finding **F14** of `user-stories.md`.

The shell owns routing, providers and interceptors (`ARCHITECTURE.md` §5.1). `US-C10-02` requires an unauthenticated visitor on any route other than sign-in to be redirected — that guard needs a router to attach to, which is this ticket.

## Scope

- `pnpm nx g @nx/angular:app web --directory=apps/web --standalone --style=scss` with tags `platform:frontend,scope:shared,type:app`.
- Angular 20.3, **standalone only**: `bootstrapApplication` with `provideRouter` and `provideHttpClient(withInterceptors([]))`. **No `NgModule`.**
- Root routes file with lazy `loadChildren` slots, plus a wildcard not-found route.
- Global SCSS entry point that will import the design-token layer from `T-C10-12`.
- Out of scope: any interceptor implementation (`T-C10-30`); Transloco setup, owned by the `NFR` epic i18n slice — declare the dependency, do not price it here; any feature library.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** the workspace **When** `pnpm nx build web` runs **Then** it succeeds.

**Given** the application **When** `pnpm nx serve web` runs **Then** the shell renders and the router resolves the default route.

**Given** the source tree **When** it is grepped for `NgModule` **Then** there is no match.

**Given** the project configuration **When** its tags are inspected **Then** they are exactly `platform:frontend`, `scope:shared`, `type:app`, and `pnpm nx lint web` passes.

**Given** a probe import in `apps/web` from any `platform:backend` project **When** lint runs **Then** it fails on the platform rule; the probe is reverted before the ticket is closed.
