# [C10] T-C10-35 · `Role` and `Permission` domain model with the PRD §4.3 catalog

## Context

`US-C10-04` requires the platform to ship with exactly the eight roles named in PRD §4.3 and their permission sets, expressed as **named permissions in the `identity-access` domain** rather than free text, so access control speaks the same vocabulary as the personas.

## Scope

- `Permission` as a closed, enumerated domain type — never an arbitrary string — covering the key permissions of PRD §4.3.
- `Role` aggregate: stable identifier, translation key for its label, and its permission set.
- The eight-role catalog declared in the domain: Requester, Organizer / League Admin, Agent (L1), Analyst (L2/L3), Change/Release Manager, Approver, Service Manager, System Administrator.
- The System Administrator set grants configuration of catalog, taxonomy, SLA policies, workflows, notifications, roles and CMDB schema, and grants **no** permission to modify or delete an audit entry (PRD §4.3, `US-C10-04`).
- Jest unit tests asserting the catalog composition role by role.
- Out of scope: persistence and the seed (`T-C10-36`), label translations (`T-C10-37`), the predicates that consume permissions (`T-C10-38`).

## Acceptance criteria

**Given** the role catalog **When** it is enumerated **Then** it contains exactly eight roles with the identifiers above and no others.

**Given** each role **When** its permission set is inspected **Then** it matches the key permissions listed for that role in PRD §4.3, expressed as enumerated `Permission` values.

**Given** the System Administrator role **When** its permission set is inspected **Then** it contains no permission to modify or delete an audit entry, and no such permission exists anywhere in the enumeration.

**Given** the `Role` aggregate **When** it is inspected **Then** its label is a stable translation key, not a user-facing string.

**Given** a permission named as a raw string anywhere in the domain **When** the library is grepped **Then** there is no such occurrence; permissions are only referenced through the enumerated type.
