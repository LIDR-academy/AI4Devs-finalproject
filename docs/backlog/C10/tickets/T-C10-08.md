# [C10] T-C10-08 · `libs/shared/domain` — identity and ticket kernel primitives

## Context

Foundation work with no user story behind it. Source: `docs/backlog/epic-map.md` → **Foundation ownership (priced once)**, the `libs/shared/domain` row listing the shared kernel primitives, priced in `C10` and citing `ARCHITECTURE.md` §4.2; and finding **F14** of `user-stories.md`.

The kernel is split across three tickets by cohesion: value primitives here, the event and clock ports in `T-C10-09`, the state model in `T-C10-10`. `Identity` is the primitive that `identity-access` builds `User` on, so it must land before `T-C10-19`.

## Scope

- Create the library: `pnpm nx g @nx/js:lib shared-domain --directory=libs/shared/domain --tags=platform:shared,scope:shared,type:domain`.
- Immutable value objects with construction-time validation and typed errors: `Identity`, `TicketReference`, `ImpactLevel`, `UrgencyLevel`, `Priority`, `DateTimeRange`.
- Jest unit tests for every invariant: valid construction, rejection of invalid input, equality, immutability.
- Out of scope: `DomainEvent`, `EventPublisherPort` and `ClockPort` (`T-C10-09`); `StateModel` (`T-C10-10`); any aggregate belonging to a context.

## Acceptance criteria

Mechanical checks — this ticket has no user scenario.

**Given** the library **When** `pnpm nx test shared-domain` runs **Then** every primitive invariant is covered and the suite passes.

**Given** the library source **When** it is inspected **Then** it imports nothing but `libs/shared/util` — no framework, no ORM, no HTTP, and no `new Date()`.

**Given** a value object **When** it is constructed with invalid input **Then** it throws a typed domain error and never returns a partially built instance.

**Given** the project **When** its tags are inspected **Then** they are exactly `platform:shared`, `scope:shared`, `type:domain`, and `pnpm nx lint shared-domain` passes.
